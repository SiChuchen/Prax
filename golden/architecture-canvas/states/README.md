# Required state intent

| State | Semantic commitment |
|---|---|
| loading | Preserve workspace orientation and communicate progress |
| empty | Explain why no architecture is visible and the next meaningful action |
| ready | Show a readable global architecture overview |
| selected | Keep selection visible and drive contextual inspector detail |
| error | Preserve recoverable context and expose a meaningful retry path |

These are intent records, not screenshots or framework components.
