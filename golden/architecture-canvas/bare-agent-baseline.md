# Bare-agent artifact baseline

This controlled artifact baseline represents the common direct translation of
the same requirement without Prax gates. It is not presented as user evidence.

- Primary navigation mirrors backend resource types: nodes, edges, groups.
- A toolbar and property panel receive equal prominence to the architecture.
- Selecting a node opens a separate detail route and loses canvas position.
- Loading and ready behavior are implicit; empty, selected, and error intent is absent.
- No rejected structural alternative or capability trade-off is recorded.
- Validation is a generic visual check rather than context-routed evidence.
