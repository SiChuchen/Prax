# Lessons package layout

Post-review knowledge absorption (spec §20.12):

- `prax-gaps.yaml` — runtime gaps observed, each classified (Knowledge Gap /
  Routing Failure / Compilation Failure / Validation Gap / Process Overhead)
- `candidate-corrections.yaml` — human corrections worth persisting as
  project-local correction memory entries (then optionally re-tested via
  PRAX-MEM-001)
- `asset-observations.yaml` — capability/asset observations (empty in this
  benchmark; registry phases not built)
- `benchmark-learnings.md` — protocol learnings for the second benchmark

Default posture: `new_general_rules: []` — findings refine scope or add
project-local corrections first; general knowledge promotion requires
independent cross-case evidence.
