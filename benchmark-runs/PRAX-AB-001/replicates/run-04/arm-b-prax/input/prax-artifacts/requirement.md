修正 Architecture Canvas 的可读性：用户拒绝 v1 交付截图——默认 fit 把对象标签压到不可读、顶层 Region 排成一条长横条、Landscape 隐藏对象却无有意义的 Region 摘要、关系线多且难以跟随、Trace 只高亮一个集合没有有序主路径、Inspector 覆盖在画布上没有相机重构、Region 边框占空间却无强可读摘要。在保留 Semantic Graph/ELK/React Flow 基础、Human Web 只读边界、现有 Canvas 数据形状与 Agent 维护契约的前提下，落实六条已共识的空间/可读性契约：1) 屏幕空间节点尺寸可读（验收单位是屏幕空间尺寸，不是 fit 前布局宽度）；2) 顶层 Region 二维组合而非长横条；3) 默认停留在 Architecture 密度而非立即 Landscape；4) 画布内容占据有效视口大部分但不要求一次放下全部几何；5) Inspector 停靠化为工作区面板且相机与有效视口必须响应；6) 稳定地图 + 有序 Trace 走廊（入口→转换→结果的可读主路径）。
