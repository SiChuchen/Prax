## 1. What I implemented

**Multi-select union impact on the Architecture Canvas**, built on the existing single-select impact emphasis already present (uncommitted) in this worktree:

- **Selection surface** (`canvas-kernel.tsx`, `architecture-canvas.tsx`): React Flow v12 native multi-selection — marquee/box drag on empty canvas (left button), modifier-click (Shift/Ctrl/Cmd) to add/remove, plain click unchanged. Panning moved to right/middle-button drag; wheel zoom, Controls and Minimap untouched. Region nodes became pointer-transparent (`style.pointerEvents: "none"`), otherwise they swallow every marquee start. `deleteKeyCode={null}` keeps the read-only contract (Backspace could otherwise delete nodes from local state). Selection events are routed through node `select` changes in a wrapped `onNodesChange` — **not** `onSelectionChange`, which ping-pongs against the controlled nodes replacement and crash-loops (found and verified in-browser).
- **Union impact read model** (`interaction.ts`): `CanvasSelection` gains a `{kind:"objects", ids}` variant; `deriveImpact` now takes the selected set — upstream/downstream are the union over all selected objects, intra-selection relationships excluded, selected objects never in their own impact sets; single-select is the `length===1` case and is bit-for-bit unchanged. Inspect-mode emphasis generalized (selected set primary, union neighborhood related, rest muted). Focus/Trace branches untouched (plus one defensive fallback).
- **Shared impact**: each impacted object tracks which selected objects reach it; `≥2` sources ⇒ shared, marked with a `⇄ Shared N×` chip (weight variant) on the card and listed first in the Inspector.
- **Aggregate Inspector** (`inspector-binding.ts`, `inspector.tsx`): new `kind:"objects"` binding — "N objects selected" heading, Selected/Upstream/Downstream/Shared counts, and Shared/Upstream/Downstream/Selection object lists whose entries lead to single-object inspection. Empty selection returns the Inspector to idle and the canvas to Browse.
- **Line-grammar compliance**: the session carried project correction `corr_canvas_impact_grammar` (no hue-coded direction, no glow), so the blue/amber impact hues from the previous iteration were removed — one established accent, direction via arrowheads + ↑/↓/⇄ glyphs, shared via border weight (verified by computed-style checks).
- Camera fits the selection union + direct neighbors under the existing per-mode contract; statusbar shows "N selected"; legend gains the Shared entry; review doc updated.

**Product decisions noted**: multi-selection lands in Inspect (Trace keeps its lens if objects are selected inside it); marquee reach is viewport-bound on virtualized large graphs (the named 15/20 and 40/70 scales render fully); pan gesture changed from left-drag to right/middle-drag (all camera affordances remain).
