# cell-j05-s05-a — 星脉 · 服务关系图谱（understand × relational-web）

面向「理解关系结构」的单页应用：在一个电商核心链路的 44 节点 / 68 关系图上，
**依赖可查、影响可追，且跟随过程永不丢失全局上下文**。

## 运行

零依赖、纯静态，无构建步骤：

- 直接双击打开 `index.html`（file:// 即可），或
- `python -m http.server 8123` 后访问 `http://127.0.0.1:8123/`
- 单文件版：`dist/index.standalone.html`（全部内联，拷走即用）

首屏即含全部数据与默认焦点（订单服务），无加载态。

## 验证 / 浏览器证据

```
powershell -ExecutionPolicy Bypass -File verify.ps1
```

自动完成：数据完整性检查（Node，可选）→ 用本机 Edge/Chrome 无头截图 4 个状态到
`evidence/` → `--dump-dom` 断言（无 JS 错误、viewBox 存在、44 节点 / 68 边全部渲染、
面板与面包屑就绪），输出 PASS/FAIL 摘要。

## 验收种子 → 设计对应：关系跟随不丢失全局上下文

1. **整图恒显**：主画布以 SVG `preserveAspectRatio=meet` 全图呈现，任何聚焦/跟随
   只改透明度与描边，不移镜头、不裁剪、不隐藏节点；画布右下角常驻「全局视图」徽标。
2. **跟随路径面包屑**：顶栏记录 A › B › C 跟随轨迹，路径在图上以金色流动虚线标出，
   点面包屑任意一站可回跳。
3. **双向半径高亮**：焦点向外 1/2/3/全部 跳，蓝环=我依赖的（上游），橙环=依赖我的
   （下游影响），按跳数渐隐并带扩散动画；非相关节点压暗至 13% 但保持可见、可点击。

## 交互

- 点节点 / 点右侧关系条目 → 跟随（路径入面包屑）
- 半径切换 1 跳 / 2 跳 / 3 跳 / 全部
- 搜索节点、图例点按按类型过滤、「只看 P0」
- 点空白处清除焦点；Esc 同效

## 结构

```
index.html                  页面骨架（多文件版入口）
styles.css                  深色主题样式
data.js                     数据集（44 节点 / 68 关系，电商交易链路，内联）
app.js                      布局（种子化力导向）+ 渲染 + 交互（无框架、无外部依赖）
dist/index.standalone.html  单文件构建（样式/数据/逻辑全内联）
verify.ps1                  本地验证 + 真实浏览器截图生成脚本
evidence/                   verify.ps1 产出的浏览器截图
```

## 数据模型

- 节点：`{id, name, type: service|data|queue|external|client, team, crit, desc}`
- 边 `[A, B, kind]`：**A 依赖 B，箭头指向被依赖方；影响沿箭头反向传播**
  - `call` 同步调用 · `data` 数据读写 · `pub` 发布事件（影响双向）· `sub` 订阅事件
- 影响范围 = 反向可达闭包；依赖范围 = 正向可达闭包（pub 边双向）
