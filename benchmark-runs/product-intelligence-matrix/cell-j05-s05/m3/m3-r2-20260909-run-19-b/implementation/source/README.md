# 星链 · 依赖全景（cell-j05-s05 · understand × relational-web）

单页静态应用：在一张**常驻依赖网络图**上理解关系结构——聚焦任意对象，沿
**上游依赖（我依赖谁）** 与 **下游影响（谁依赖我）** 连续多跳跟随；
跟随过程中**全图始终可见**，非相关对象仅弱化、不移除，节点位置不动
（orientation invariants）。验收种子：**关系跟随不丢失全局上下文**。

## 打开方式

- 直接双击 `index.html`（file:// 纯静态，无构建、无外部服务、无请求）；或
- `python -m http.server` 后访问 `http://localhost:8000/`。

首屏即用：数据内联于 `data.js`，`app.js` 末尾同步初始化，页面加载完成即处于
ready（默认聚焦枢纽对象 `dws_trade`），**不存在加载态**。

## 功能

| 能力 | 说明 |
|---|---|
| 全图常驻 | 24 对象 / 33 关系全部渲染；聚焦时非相关元素 opacity 降至 0.12 保留 |
| 跟随 | 点击节点 / 检查器邻居列表 / 关系两端 → 沿关系移动 |
| 深度 | 1 跳 / 2 跳 / 全链路（顶栏分段控件或快捷键 `1` `2` `0`） |
| 方向着色 | 上游依赖 = 青色；下游影响 = 橙色；⚑ = 关键链路 |
| 关系一等 | 点击边（或检查器「关系明细」）查看类型 / 关键度 / 说明，两端可跳转 |
| 跟随路径 | 面包屑记录连续跟随序列，可点击任意一步回退 / `Backspace` 回退 |
| 全局上下文徽标 | 右上常驻：全图 N 对象均可见 · 高亮 X 节点 · Y 关系 · 其余弱化保留 |
| 搜索 | `/` 聚焦搜索框，名称/id/类型匹配，`↑↓` `Enter` 跟随 |
| 类型过滤 | 关系类型 chip（数据 / 写入 / 调用 / 派生），过滤同时参与跟随遍历 |
| 视图 | 滚轮缩放（对准光标）、空白拖拽平移、双击复位 |
| 状态 URL | `#p=路径&d=深度&e=边&off=关闭类型&h=1`：跟随路径可分享/刷新复现，浏览器前进后退可用 |
| 状态覆盖 | ready（默认聚焦）/ selected（节点或边）/ empty（`#h=1` 未聚焦引导）/ error（`#p=不存在`）/ loading（保留契约位——同步初始化，实际不可见） |

## 键盘

`/` 搜索 · `↑↓`+`Enter` 选择跟随 · `Backspace` 路径回退 · `Esc` 清除选边/回退/回全景 · `1/2/0` 深度

## 结构

```
index.html   壳：顶栏（搜索/深度/类型过滤）+ 画布 + 检查器
styles.css   暗色图工作台 token 与组件样式
data.js      内联数据：电商数据平台血缘（方向语义 A→B = A 依赖 B）
app.js       确定性布局、可达性 BFS、高亮/弱化渲染、检查器、hash 状态机
evidence/    证据目录（NOTES.md 说明现状与补采断言；PNG 需运行 capture-evidence.ps1 生成）
```
