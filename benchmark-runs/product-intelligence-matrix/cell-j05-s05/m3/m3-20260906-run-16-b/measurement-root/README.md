# DepAtlas · 服务依赖图谱

cell-j05-s05（understand × relational-web）—— 一个用于**理解关系结构**的单页 Web 应用：
在一张始终完整可见的服务依赖全景图上，逐跳跟随**依赖**与**影响**，全程不丢失全局上下文。

## 打开方式

无需构建、无外部服务、无网络请求：

- 直接双击打开根目录 `index.html`（file:// 即可），或
- 任意静态服务器指向本目录，如 `python -m http.server` 后访问根路径。

页面加载完成即处于可用状态：数据集内联于 `data.js`，随首屏同步渲染，无加载态。

## 核心交互（验收种子：关系跟随不丢失全局上下文）

- **选择**：点击地图节点 / 连线（或 Tab + Enter），右侧详情面板显示属性、
  直接/传递依赖、影响面（改动可能波及的服务）。
- **跟随**：在详情面板点击「依赖 / 被依赖」关系项即沿该跳延伸路径；
  顶栏路径条记录每一跳的方向（→ 依赖 / ← 被依赖），可点击任意步回退。
- **全局上下文**：聚焦时其余节点与连线**置灰但绝不移除**，全图保持原位；
  路径条实时显示「路径 N 节点清晰 / 全图 24 服务 · 保持原位可见」。
- **影响面 / 依赖闭包**：一键高亮传递闭包（琥珀虚线圈），看清改动波及范围。
- **定位**：搜索框（按 `/` 聚焦）按名称/中文名定位服务，选中不离开地图。
- **返回全局**：`Esc` 或「重置视图」随时回到全图。
- **深链**：状态写入 URL hash，可直接分享，如
  `index.html#follow=web-app>api-gateway>order-service>payment-service`、
  `index.html#select=order-service&impact=deps`。

## 数据集

虚构电商系统「星衡电商」：24 个服务、4 个团队、4 个层级（客户端 → 网关 → 业务服务 → 数据与基础设施）、
40 条带类型（调用 / 数据）与关键度的依赖关系。仅作演示，不代表任何真实系统。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 入口与页面骨架 |
| `styles.css` | 深色专业工具主题（token 内聚 `:root`） |
| `data.js` | 内联数据集（24 服务 / 40 依赖关系） |
| `app.js` | 渲染、遍历、闭包、搜索、键盘、深链（无依赖 vanilla JS） |
| `evidence/` | 真实浏览器截图与 DOM 证据（headless Edge 采集） |

键盘：`Tab` 遍历节点与连线（可见焦点环），`Enter`/`Space` 选中，`Esc` 返回全局，`/` 聚焦搜索。

技术栈：原生 HTML/CSS/JS，零依赖、零构建。
