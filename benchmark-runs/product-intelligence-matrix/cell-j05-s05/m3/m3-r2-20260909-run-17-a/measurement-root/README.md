# 脉络 Trace · 服务依赖图谱

cell-j05-s05（understand × relational-web）交付物。单页静态 Web 应用：在一张**永远完整可见**的全景依赖图中，跟随任意节点/关系的依赖（蓝）与影响（橙），轨迹与全局上下文全程保留。

## 运行

无构建、无外部服务、无 CDN。直接双击打开根目录 `index.html` 即可（file:// 协议可用）；首屏即渲染完成态——数据内联于 `data.js`，与首屏同步就绪，无加载态。

也可用任意静态服务器：`python -m http.server` / `npx serve`。

## 操作

| 操作 | 结果 |
|---|---|
| 点击节点 | 选中并跟随：蓝色出边=它依赖谁，橙色入边=谁依赖它；侧栏给出直接/闭包/链深统计与两份可点击关系清单 |
| 点击连线 | 选中**关系本身**（关系即内容）：类型、语义标签、中断波及面 |
| 轨迹条 | 走访路径面包屑（含逐跳关系类型），点击任意一笔回溯；「走访覆盖 n/35」恒显 |
| 方向 × 深度 | 依赖 / 双向 / 影响 × 1/2/3 跳 / 闭包，随选随算 |
| 路径分析 | 任选两节点，同时求依赖路径与影响路径，路径常亮、节点可顺藤查看 |
| 检索 | 按名称 / ID / 域 / 团队过滤，回车直达 |
| 深链 | 选中态写入 URL hash（如 `#sel=pg-users&dir=impact&depth=99`），可分享当前视角 |
| Esc / 点击空白 / 重置 | 退路径态 / 回总览 / 全部复位 |

**验收种子对应**：关系跟随不丢失全局上下文 —— 全图 35 节点常驻一屏（跟随只做明暗聚焦、不做视图跳转）、层带背景标示所在层、轨迹条与步骤徽标保留来路、走访覆盖率恒显。

## 数据

`data.js`：青梧电商平台，35 节点（接入 4 / 服务 16 / 消息 4 / 数据与外部 11）、56 关系（同步 28 / 事件 15 / 数据 13）。边方向语义统一为 **from 依赖 to**（to 中断直接波及 from）。

## 文件

- `index.html` · `styles.css`（设计令牌：dataviz 已验证暗色系，色板经 `validate_palette.js` PASS）· `data.js` · `app.js`（分层 barycenter 全景布局、BFS 闭包/路径、最长影响链、渲染与交互）
- `evidence/`：真实浏览器（headless Chrome）截图 4 张：初始跟随态、影响闭包、依赖闭包、自检报告
- 自检：`index.html?selftest=1` 在真实浏览器中执行「跟随链 → 影响闭包 → 双向路径 → 关系选中 → 复位」全链路并输出 PASS/FAIL 报告
