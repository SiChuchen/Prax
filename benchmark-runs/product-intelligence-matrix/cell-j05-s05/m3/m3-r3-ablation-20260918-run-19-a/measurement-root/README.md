# 脉络 · 依赖关系网（cell-j05-s05 · understand × relational-web）

理解**关系结构**的单页静态应用：以一张完整常驻的关系网为底，**跟随**依赖与影响，
全程不丢失全局上下文（验收种子）。

## 运行

零依赖、零构建、零网络请求。任选其一：

- 直接双击打开 `index.html`（file:// 即可）
- 或本地起服务：`python -m http.server 8123` → http://localhost:8123

## 怎么用（对应成功标准「依赖与影响可跟随」）

| 操作 | 效果 |
|---|---|
| 点击任意节点 | 聚焦；相邻一跳加亮，其余节点**降暗但不隐藏**，全图仍在 |
| 点击相邻节点 | **跟随**：路径累计为面包屑（可回退、换向、分支），跟随边高亮流动 |
| 面板关系行 / 图上连线 | 关系本身成为一等对象：类型、协议、关键性、说明 |
| `依赖闭包` / `影响闭包` | 传递依赖集 / 影响面（blast radius）整体加亮 |
| 搜索框 / 深链 | 跳转节点；`#p=order>mq>notify&m=impact` 可分享当前跟随状态 |

方向约定：`A ──▸ B` 表示 **A 依赖 B**；顺箭头走 = 它依赖什么，逆箭头走 = 谁受它影响。
