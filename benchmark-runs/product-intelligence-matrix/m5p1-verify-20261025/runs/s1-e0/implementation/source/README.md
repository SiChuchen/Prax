# 多维棱镜 · 数据探索工作台

cell-j13-s10（explore × dimensional-space）交付物：一个单页多维数据探索工作台。
用户任务 **explore 多维数据**，成功标准 **维度切换不重置认知**，验收种子 **过滤/投影状态有归属且可回退**。

## 打开方式

- 直接双击打开根路径 `index.html`（无构建、无网络、无外部服务；普通 `<script>` 引用，`file://` 可开）；
- 或任意静态服务器：`python -m http.server` 后访问 `http://localhost:8000/`。

页面加载完成即处于可用状态：数据集由确定性 PRNG（mulberry32(20260913)）在首屏同步内联生成
（2,600 行零售销售事实表），**无加载态**。

## 功能对照

| 简报要求 | 实现 |
|---|---|
| explore 多维数据 | 行维度×列维度×度量的交叉热力表；顶栏/维度轨道均可换轴；行头树层级下钻（品类 3 层、渠道 2 层、区域 2 层）；4 种度量（销售额/毛利/订单数/退货率）；排序 |
| 维度切换不重置认知 | 换轴动作白名单只触碰 `rowDim/colDim`；过滤器、锚定集合、度量、排序、各维度展开态全部保留；换轴后 toast + 投影区常驻「认知锚」行回显『已保留 N 项过滤 · M 处锚定 · 度量 · 排序』 |
| 过滤/投影状态**有归属** | 每个过滤 chip 携带来源徽标（维度轨道/投影区/顶栏/状态归属栏/系统）；锚定 chip 标注来源，换轴后未命中者标「悬空」；底部**状态轨迹**每条记录动作+对象+来源+时刻 |
| 状态**可回退** | 轨迹任意条目点击回滚（时间旅行，未来步保留可再前进）；顶栏撤销/重做（Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z）；重置全部（重置本身入轨，可再回退）；过滤 chip × 单条移除、锚定单条移除、一键清除全部 |
| 层级性（中） | 品类›子类›单品、渠道类型›渠道、大区›省区 三棵层级树，行头/轨道双处可展开下钻，展开态按维度记忆、跨换轴保留 |
| 首屏即用 | 同步内联数据，`render()` 在脚本尾部同步完成首帧 |

信息形状对齐 shape 束：unbounded 基数（~2,600 行事实表 + 全组合可下钻）、高密度（一屏 ~200+ 单元格）、
高维度性（5 维度 × 4 度量投影空间）、中层级（3 棵树）、无空间性（无地图）、无比较需求（无对比视图）。

## 技术栈

零依赖原生 HTML/CSS/JS（`index.html` + `app/data.js` + `app/app.js` + `app/style.css`）。
选择理由：交付约束要求静态直开 + 首屏即用 + 本地可运行；零构建使 `file://` 直开成为可能，
消除工具链与网络风险（决策 `static-no-build` 已记录于 Prax 会话）。

### 浏览器实测记录（Prax 自带浏览器测量，receipts 存于其 state root）

5 轮真实浏览器测量（1280×860 与 1440×900 双视口）驱动修复：

1. r1：横向溢出（gridWrap @1280）、11 对文字对比度 <4.5（热力格中段色 + 禁用按钮 45% 透明度）、
   54 个 <24px 命中目标、焦点序回跳 → 全部修复：热力梯度封顶亮度（全矩阵深色文字 ≥4.5:1）、
   禁用态改实色、自绘 24×24 复选框/24px caret/chip-x、轴选择器上移顶栏；
2. r2：仅剩 1 处焦点序回跳（根因：轨道内容 ~1050px 超出 750px 列高被裁剪）；
3. r3：实测暴露碰撞对坐标 → 结构性修复：维度轨道压入 730px < 750px（不滚动、不裁剪）、
   默认投影改平坦×平坦（客群×季度，消除初始跨列回跳停准点），热力/溢出/目标尺寸/碰撞全部转绿；
4. r4-r5：10/10 通过，validation 提交 evidence 后 status=PASS、missing_evidence=[]、unresolved=[]。

**如实披露的残留**：最终两处修订（默认轴改 segment、轨道间距收紧）晚于最后一次浏览器实测轮次
