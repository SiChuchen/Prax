# StructEd · 结构文档工作台

cell-j08-s08 · **edit × single-document** —— 单页结构化文档编辑器。
用户任务：编辑文档；成功标准：**编辑不破坏结构**；验收种子：**结构化编辑与预览一致**。

## 运行

零依赖、零构建：直接双击打开 `index.html`（或任意静态服务器指向本目录，如
`python -m http.server 8000`）。页面加载完成即处于可用状态——内置示例文档随首屏
同步渲染，没有任何加载态。

- `index.html#selftest` —— 打开时自动运行内置自检套件（结果同时输出到控制台与「结构体检」面板）。
- 控制台亦可手动触发：`__structed.runSelfTests()`。

## 界面（单主屏，三栏）

| 栏 | 内容 |
|---|---|
| 大纲 | 由标题层级自动生成的目录（含 1 / 1.1 自动编号），点击跳转 |
| 编辑器 | 逐块结构化编辑：块类型受控切换、上移/下移/复制/插入/删除、唯一 H1 标题 |
| 预览 | 同一模型的实时派生视图：自动编号、列表聚合、引用/提示框排版 |

底栏状态：块数 / 标题数 / 字数、同步时间徽标、最近操作消息。左栏下部是**结构体检**
面板：实时校验结果 + 一致性自检（模型节点数 ↔ 预览节点数）。

## 「编辑不破坏结构」的实现

全文只有一份数据模型 `doc = { title, blocks[] }`；大纲、编辑器、预览都由它派生，
任何编辑先改模型再同步重绘——**一致由构造保证**。结构由三条规则保护：

- **R1 唯一 H1**：文档标题是独立字段，恒为全文唯一一级标题，不提供任何能改变其级别的操作。
- **R2 层级连续**：内容标题仅 H2/H3；所有结构性操作（改类型/移动/复制/插入/删除）
  先在副本上试运行，若产生「标题级别 > 前一标题级别 + 1」的跳跃则**整体拒绝**，
  并用 toast 说明原因（例如删除中间 H2 导致后续 H3 悬空）。
- **R3 标题非空**：键入过程允许瞬时为空，但编辑器、预览、体检面板三处实时标记。

其余设计：撤销/重做（Ctrl+Z / Ctrl+Y，含键入合并快照）、Enter 新建段落（守卫中文
输入法合成期）、空块 Backspace 删除、导出/复制 Markdown（与模型逐块对应）、
localStorage 自动保存 + 「重置示例」。

## 自检覆盖（`#selftest`）

1. 示例文档初始结构有效；2. H1→H3 跳级被拒绝且模型不被污染；3. 破坏性删除被拒绝；
4. 非法移动被拒绝、合法移动放行；5. 60 步随机守卫操作后结构仍有效；
6. 随机操作后模型节点数 = 预览节点数；7. Markdown 导出与模型一致。
