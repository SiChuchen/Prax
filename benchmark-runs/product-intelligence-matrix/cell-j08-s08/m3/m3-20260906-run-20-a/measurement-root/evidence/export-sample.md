## 2. 核心能力

检测引擎围绕“发现—描述—确认”三个环节构建，当前版本具备以下能力：

- 像素级变化图斑提取，最小图斑 64 平方米
- 双时相影像自动配准，配准误差低于 0.5 像素
- 图斑置信度分级输出（高 / 中 / 低），支持 `Webhook` 回调通知

## 3. 使用流程

1. 上传两期影像，框选或导入 ROI 边界
2. 选择检测模板（农业 / 国土 / 通用）
3. 提交任务并获取回执编号
4. 在结果页复核图斑，导出边界与统计

整个流程平均耗时 8 分钟；任务回执包含每个图斑的边界 `GeoJSON` 以及前后两期影像的裁剪对照图。

## 4. 边界与非目标

本期不做三维变化检测，不处理海洋目标，也不承诺对云量超过 30% 的影像给出可用结果。超出上述范围的请求将被明确拒绝，而不是返回低质量结果。

> **【注意】已知限制**
> 冬季落叶林区域的误报率约为 12%，计划在 v1.3 引入物候校正模型后收敛到 6% 以内。
