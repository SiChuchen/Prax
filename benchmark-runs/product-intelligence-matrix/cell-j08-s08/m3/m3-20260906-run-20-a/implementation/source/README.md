# 构文 DocForm · 结构化文档编辑器

> cell-j08-s08（edit × single-document）交付物 · 单页纯静态应用 · 零依赖零构建

## 打开方式

直接双击 `index.html`（或任意静态服务器指向本目录）。无外部请求、无后端、无账号；
页面加载完成即处于可用状态——首屏内置一篇完整示例文档，无加载态。

## 产品定位

**编辑不破坏结构，预览与结构化编辑实时一致。**

文档模型为 `标题 → 小节(H2，层级固定) → 内容块`，内容块仅三种受控类型：

| 类型 | 字段 | 说明 |
|---|---|---|
| 段落 p | text | 支持 `**加粗**` `*斜体*` `` `代码` `` 行内标记 |
| 列表 list | variant, items[] | 有序 / 无序 |
| 提示框 callout | tone, title, text | info / success / warn / danger 四级 |

所有编辑经由表单约束完成（无富文本、无 HTML 注入、层级由模式固定），
右侧预览由文档数据实时渲染——**编辑与预览在数据层同源，结构上不可能不一致**。

## 功能

- **结构化编辑**：文档标题 / 副标题 / 小节标题 / 分类型内容块表单；块级增删、复制、上下移
- **实时预览**：任何编辑即时同步，变更块闪烁定位；「预览已同步」徽标显示最近同步时刻
- **结构检查**：空标题（错误）、空小节 / 空段落 / 空列表项 / 空提示框（建议），点击问题可定位
- **大纲导航**：左栏大纲选择、上移 / 下移小节、新增小节、两步确认删除
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y，连续输入自动合并为一个撤销点（上限 100 步）
- **本地草稿**：自动存 localStorage（file:// 下亦可用），重开页面恢复；「还原示例」一键重置
- **导出**：Markdown / 独立 HTML 下载、Markdown 复制到剪贴板；Ctrl+S 手动存草稿

## 实现说明

- 单文件 `index.html`（内联 CSS/JS，原生 DOM，无框架无依赖），全部文本经
  `textContent` / 受控行内标记解析渲染，XSS-safe by construction
- 中文排版：正文宋体系衬线、两端对齐；提示框四级色彩语义
- 响应式：>1240px 三栏（大纲 / 编辑 / 预览），窄屏逐级折叠
