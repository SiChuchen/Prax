# 文枢 StructDoc · 单文档结构化编辑器

> 基准格：product-intelligence-matrix · cell-j08-s08（edit × single-document）
> 用户任务：**编辑文档**；成功标准：**编辑不破坏结构**；验收种子：**结构化编辑与预览一致**

从零实现的单页 Web 应用：把「编辑一份文档」建模为**结构化块编辑 + 同源实时预览**。
文档的最小结构单元是「块」（标题/正文/列表项/引用/代码/分割线）；文本只能改块内内容，
结构变更（移动、缩进、升降级、转换、插入、删除）全部走显式结构操作 —— 因此**编辑动作
在构造上不可能破坏文档结构**；预览、大纲、统计、Markdown 导出全部派生自同一份块模型，
**编辑器与预览天然一致**。

## 运行

零依赖、零构建、离线可用：

- 直接双击打开 `index.html`（file:// 协议即可），或
- 任意静态服务：`python -m http.server` / `npx serve` 后访问根路径

页面加载完成即处于可用状态：示例文档（《领航 App 3.2 版本发布说明（草案）》，17 块）
随首屏同步渲染，**无加载态**。

## 功能

| 区 | 能力 |
|---|---|
| 顶栏 | 文档标题、统计（块数/字数/阅读时长）、同步徽标（编辑中…/已同步·时刻）、撤销/重做（Ctrl+Z / Ctrl+Y）、历史版本回溯、导入 Markdown、导出 Markdown（Ctrl+S：复制 / 下载 .md）、重置示例 |
| 大纲 | 由标题块实时派生的层级大纲；结构告警角标；点击定位块 |
| 编辑器 | 逐块编辑：类型徽章 + 块级操作（上移/下移/升降级或缩进/转换类型/下方插入/删除）；标题与列表 Enter 智能新建下块；空块 Backspace 删除；**结构检查条**（多一标题/跳级/空标题）+ 单项与一键修复 |
| 预览 | 与编辑器同一模型的实时排版渲染（标题层级、多级嵌套列表、引用、代码块、分割线） |

结构检查规则（可修复，均为结构化操作而非文本改写）：
① 一级标题块至多一个；② 标题不得跳级（如 H1→H3）；③ 不允许空标题。

## 简报 facet 对应

| facet | 本实现的体现 |
|---|---|
| 基数 one | 单文档单屏，无文档列表 |
| 层级性 中 | 标题层级（H1–H3）+ 列表嵌套（0–3 级缩进），大纲树可视化 |
| 时间性 中 | 快照历史（带操作标签与时刻）、可回溯任意历史点、撤销/重做 |
| 密度 低 | 一屏三栏、逐块聚焦，无信息过载 |
| 维度性 中 | 块类型维度（6 类）× 结构操作维度（移/缩/转/插/删）|
| 易变性 中 | 结构检查 + 快照历史兜底「易变」的编辑过程 |
| 不确定性 低 / 关系性 低 / 空间性 none / 比较需求 none | 不设协同、比较、空间画布等机制 |

## 架构

```
index.html      骨架（三栏 + 顶栏 + 浮层）
styles.css      全部样式（无外部字体/图标，离线可用）
doc-model.js    纯数据模型：块结构、Markdown 序列化/解析、lint 与修复、结构操作、统计
app.js          DOM 层：渲染调度（文本编辑只刷派生视图，不打断输入）、事件、历史、导入导出
tests/          node 原生断言单元测试（无依赖）
```

一致性保证：`serializeMarkdown`（导出）、预览渲染、大纲派生读取的都是同一份
`doc.blocks`；单元测试验证 `parse(serialize(sample))` round-trip 深相等。
