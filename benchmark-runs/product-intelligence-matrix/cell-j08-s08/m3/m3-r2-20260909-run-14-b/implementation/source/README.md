# Structura · 结构文档工作台

cell-j08-s08（edit × single-document）交付物：一个**单文档结构化编辑器**。
左侧按块编辑文档结构，右侧实时预览最终排版；编辑与预览渲染自**同一数据模型**，
因此"结构化编辑与预览一致"是结构保证而非视觉巧合。连续的结构检查
（层级跳跃、空标题、空列表…）保证**编辑不破坏结构**。

## 运行

无构建、无依赖、无外部服务：

- 直接双击打开根目录 `index.html`（file:// 即可），或
- `python -m http.server` 后访问 `http://localhost:8000/`

页面**加载完成即处于可用状态**：初始示例文档随 `data.js` 内联进首屏，
没有任何网络加载或加载态。

## 功能

| 能力 | 说明 |
|---|---|
| 结构化编辑 | 块类型：H2–H4 标题 / 段落 / 有序·无序列表 / 引用 / 代码 / 提示 / 分隔线；就地编辑，悬停显示块操作（增、插、复制、移动、删） |
| 实时预览 | 与编辑器共享同一文档模型，每次变更同帧重渲；点击预览回选编辑块（双向同步） |
| 大纲 | 由标题块**派生**的分区树（非独立存储），点击双视图跳转 |
| 结构检查 | 连续校验：无标题、层级跳跃、空标题/段落/列表、空引用、标题收尾；每条可定位、多数可一键修复（修复可撤销） |
| 撤销/重做 | 快照栈（上限 100 步），删除与"重置示例"均可撤销 |
| 视图切换 | 编辑 / 分屏 / 预览 |
| 导出 | Markdown 与独立 HTML，由同一模型序列化，与预览一致 |
| 本地留存 | 自动保存到 localStorage；「重置示例」随时回到内置文档 |

### 键盘

- `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）：撤销 / 重做
- `Enter`：新建块（列表项中为新增列表项）；`Shift+Enter`：软换行
- `Tab` / `Shift+Tab`（标题块内）：降低 / 提升标题层级
- `Alt+↑` / `Alt+↓`：上移 / 下移当前块
- 空块内 `Backspace`：删除该块
- `Esc`：关闭插入菜单

## 技术栈

原生 HTML / CSS / JavaScript，零依赖、零构建。文件结构：

```
index.html   页面骨架（Application Shell：顶栏 + 三栏工作区 + 状态条）
styles.css   设计令牌与全部样式
data.js      内联初始文档（首屏就绪的保证）
app.js       应用逻辑（模型 / 渲染 / 校验 / 历史 / 导出）
```

## 状态模型

- **ready**：加载即就绪（数据内联，同步初始化）
- **loading**：同步内联初始化，不存在可观测加载态（简报约束）
- **empty**：文档为空时编辑区/预览区各呈现空状态与插入入口
- **selected**：编辑区、预览区、大纲三处同步高亮选中块
- **error**：结构检查错误以诊断面板 + 顶栏健康度徽标呈现，可定位、可修复
