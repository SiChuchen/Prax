# Docloom — 单文档结构化编辑器（cell-j08-s08）

编辑 × 单文档：对唯一文档做**结构化编辑**（节字段 + 层级大纲操作），保证
**编辑不破坏结构**，且**结构化编辑与预览一致**。

## 打开方式

无构建、无外部依赖：直接双击打开根目录 `index.html`（file:// 即可），
或任意静态服务器（如 `python -m http.server`）。

页面加载完成即处于可用状态——初始示例文档随首屏内联，无加载态。

## 功能

- **三栏工作台**（List-Detail 适配）：大纲树 | 节编辑器 | 实时预览，同一状态源派生，天然一致。
- **结构操作白名单**：添加子节 / 添加同级节 / 上移 / 下移 / 升级 / 降级 / 删除。
  非法操作（层级越界、边界移动、无前节降级）一律禁用并说明原因；
  删除含子节的节时二选一（子节上移 / 连同子树删除），**绝不产生孤儿节**。
- **结构检查**：工具带徽标实时计数，面板列出空标题 / 空正文 / 同级重复标题，点击定位；
  结构不变量（层级连续 ≤ 4 级、无孤儿节）恒满足并明示。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z），覆盖全部字段与结构操作；「重置示例」经确认弹窗且可撤销。
- **预览联动**：编辑击键级同步；点击预览或检查项反向定位大纲。
