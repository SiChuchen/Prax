# Locus · 落位画布 — cell-j07-s07（create × spatial-workspace）

单页空间工作台：**物理落位即意图** —— 把对象放进哪个区，它就是什么状态，
不需要点菜单改状态；同时**每个空间操作都有键盘等价物**（验收种子）。

## 运行

零构建、零依赖、无外部服务。两种方式任选：

- 直接双击打开 `index.html`（file:// 即可完整运行）
- 或本地服务：`python -m http.server 8321` → http://127.0.0.1:8321

首屏即就绪：9 个初始对象内联在 `core.js`（`seedObjects`），页面加载完成即为
可用状态，无任何加载态。

## 设计对应

| 简报项 | 实现 |
|---|---|
| user_job: create × 空间对象 | 双击空白 / `N` 创建 canvas 对象，落点即创建点 |
| 成功标准: 落位即意图 | 三个语义区（待选池/就位区/定稿区）；对象的中心点落在哪个区，区归属、徽标、计数、状态栏即随之改变；拖拽跨区实时高亮目标区并在落位时提示 |
| 判别: 空间操作必须有键盘等价物 | 见下表，全量覆盖；应用内按 `?` 可见同一张表 |
| shape: many/medium/physical | 多对象自由画布 + 栅格吸附 + 区域（区）物理结构 |
| 交付约束 | 纯静态 HTML/CSS/JS，无构建产物需求，未部署 |

## 空间操作 ⇄ 键盘等价物

| 意图 | 鼠标 / 触控 | 键盘 |
|---|---|---|
| 新建 | 双击空白 | `N` |
| 选择 | 点选 / 框选 / Shift 加选 | `Tab` 循环 · `Ctrl+A` · `Esc` |
| 移动 | 拖拽 | 方向键（栅格 20px）· `Shift+方向键`（1px） |
| 平移画布 | 空格/中键/`Alt`+拖拽 | 未选中时方向键 |
| 缩放 | 滚轮（指针为中心） | `+` `−` · `0` 复位 · `1` 适应全部 |
| 落位改区 | 拖入目标区 | `Ctrl+1/2/3` |
| 层级 | — | `[` `]` |
| 复制 / 删除 | — | `Ctrl+D` / `Delete` |
| 编辑标题 | 双击对象 | `Enter` / `F2`，`Enter` 提交 `Esc` 取消 |
| 撤销 / 重做 | — | `Ctrl+Z` / `Ctrl+Y` |
| 栅格吸附 | 工具栏开关 | `S` |

## 文件

- `index.html` — 结构 + 工具栏 + 帮助面板（快捷键全表）
- `styles.css` — 暗色画布、区/对象样式
- `core.js` — 状态、初始数据、区归属判定、渲染、撤销栈
- `input.js` — 指针（拖拽/框选/平移/缩放）与键盘命令、工具栏
- `evidence/` — 真实浏览器截图与验证记录

规模：主屏 1 个；无后端、无账号、无持久化（刷新回到初始数据）。
