# 落位 LoWei · 空间排布画板

cell-j07-s07（create × spatial-workspace）交付物。核心命题：**落位即意图**——
物理空间排布本身承载语义：物品放进哪个分区、离谁近、是否挡住动线，就是用户的意图；
应用负责把这份意图读出来（分区归属、建议、冲突警告）。

## 运行

纯静态、零依赖、无构建步骤。双击 `index.html`（或任意静态服务器指向本目录）即可。
页面加载完成即处于可用状态：示例工作室（10 件物品 + 4 个分区）内联于 `data.js`，随首屏就绪，无加载态。

## 主屏

单屏应用：左侧物品栏（8 类物品）· 中央房间画布（窗边采光带 / 动线通道 / 储物区 / 休闲区）·
右侧检查器（名称、精确坐标、分区归属、建议与冲突）· 底部状态栏（模式提示 + 落位叙述）。

## 键盘等价物（验收种子：空间操作有键盘等价物）

| 操作 | 鼠标 | 键盘等价 |
|---|---|---|
| 创建 | 物品栏点击后画布盖印 / 拖入 | `1-8` 选型 → `N` 自动寻空位落位 |
| 移动 | 拖拽（10px 网格吸附） | 方向键 = 10px 步进；`Shift`+方向键 = 1px 微调 |
| 精确落位 | — | 检查器 X / Y 直接输入坐标 |
| 旋转 | — | `R` / `Shift+R`（±90°） |
| 层级 | — | `[` 下移一层 / `]` 上移一层 |
| 选择 | 点击 | `Tab` / `Shift+Tab` 循环；`Esc` 取消 |
| 重命名 | 双击输入框 | `Enter` / `F2` |
| 复制 / 删除 | 按钮 | `D`（或 `Ctrl+D`）/ `Delete` |
| 撤销 / 重做 | 按钮 | `Ctrl+Z` / `Ctrl+Y` |
| 帮助 | ⌨ 按钮 | `?` |

应用内 `?` 可随时查看同一张表。

## 文件

- `index.html` — 结构 + 快捷键面板
- `styles.css` — 视觉（纸质画布 + 分区语义层）
- `data.js` — 房间、分区、物品类型、初始排布（内联数据）
- `app.js` — 状态、几何语义（分区归属/重叠/通道占用）、交互与键盘命令

无后端、无账号、无外部服务、不部署；状态仅在内存中（刷新即回到示例初始布局）。
