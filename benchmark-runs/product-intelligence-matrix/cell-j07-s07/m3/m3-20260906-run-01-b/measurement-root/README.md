# 落位台 SetPlot — cell-j07-s07（create × spatial-workspace）

工作坊开放日的平面布置板：**落位即意图** —— 把物件拖到（或用方向键移到）某个分区，
它的用途标签即时由位置推导（`placed_in` 关系），全程无表单、无属性面板。
每个空间操作都有**键盘等价物**（按 `?` 查看速查表）。

## 运行

零依赖、零构建即可运行：

- 直接双击打开根目录 `index.html`（`file://` 静态打开即可用）；
- 或任意静态服务器：`npx serve .`

构建（可选）：`npm run build` → 产出自包含的 `dist/index.html`（CSS/JS 内联，
同样可直接静态打开）。

页面加载完成即处于可用状态：初始平面图（4 个语义分区、13 件物件）随首屏内联，
无加载态。状态保存在内存中，刷新即回到初始布置。

## 键盘等价物（验收种子）

| 操作 | 键 |
|---|---|
| 循环选择 | `Tab` / `Shift+Tab` |
| 全选 / 取消 | `Ctrl+A` / `Esc` |
| 新建物件 | `N`（自动找空位）或双击画布空白 |
| 移动 | 方向键（一格）；`Shift+方向键`（大步）；`Alt+方向键`（智能对齐吸附） |
| 对齐 | `1/2/3` 左·水平中·右；`4/5/6` 顶·垂直中·底（单选对齐所在分区，多选组内对齐） |
| 均分 | `d` 水平 / `Shift+D` 垂直（≥3 件） |
| 复制 / 删除 / 重命名 | `Ctrl+D` / `Del` / `Enter` |
| 层级 | `[` 后移 / `]` 前移 |
| 网格吸附 | `g` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） |
| 键位速查 | `?` 或 `k` |

指针等价：点选、`Shift+点击` 加选、框选、拖拽移动（自动吸附参考线）、双击重命名。

## 设计（Prax 会话 ds_20260907155956_c08ebec2）

- 模式：`PAT-CANVAS-WORKSPACE`（+ `PAT-WORKSPACE`）—— 单一主导画布，
  上下文检查以底部状态条实现（不开侧栏），工具条安静。
- 区域契约：`dominant_workspace` 主画布 / `supporting_toolbar` 顶栏 /
  `contextual_inspector` 状态条 / 键位速查覆盖层（任务驱动）/ 对齐参考线（任务驱动）。
- 状态机：单一 `canvas_controller` 所有者（selection / inspector / query / mode）；
  撤销栈保障可逆；破坏性操作（删除）可一键撤销。

## 文件

- `index.html` + `styles.css` + `app.js` — 应用本体（经典脚本，无框架、无外部依赖）
- `build.mjs` — 自包含构建脚本（Node 内置模块）
- `evidence/` — 真实浏览器截图与旅程记录（验证证据）
