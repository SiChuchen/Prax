画布已空

按 N 新建物件，或双击任意位置直接落位。

键盘等价物速查

每个空间操作都有键盘等价物 —— 摆放即配置，全程无需表单。

选择

  • Tab / Shift+Tab循环选择下一件 / 上一件
  • Ctrl+A全选
  • Esc取消选择
  • Shift+点击加选 / 减选（指针）

新建与编辑

  • N新建物件（自动寻找空位）
  • Ctrl+D复制选中
  • Del / Backspace删除选中
  • Enter重命名选中物件
  • 双击空白 / 双击物件原地新建 / 重命名（指针）

移动与对齐

  • 方向键微移（一格）
  • Shift+方向键大步移动
  • Alt+方向键移动并智能对齐吸附
  • 123左对齐 / 水平居中 / 右对齐
  • 456顶对齐 / 垂直居中 / 底对齐
  • d / Shift+D水平均分 / 垂直均分（≥3 件）
  • 拖拽自动吸附对齐参考线（指针）

层级、撤销与视图

  • [ / ]后移 / 前移一层
  • g网格吸附 开 / 关
  • Ctrl+Z撤销
  • Ctrl+Y / Ctrl+Shift+Z重做
  • ? / k打开本速查
落位即意图：把物件移进某个分区（拖拽或方向键），用途标签即时由位置推导。
