# 落位 Floorcraft · 空间布局工作台

cell-j07-s07（create × spatial-workspace）交付物：单页静态 Web 应用。
**落位即意图**——对象的物理位置（中心点所在分区）就是它的归属；摆放即数据，不填表单。

## 打开方式

直接双击 `index.html`（file:// 协议即可，无需构建、无外部依赖、无网络请求）。
页面加载完成即处于可用状态：27 个空间对象随首屏内联渲染，无加载态。

## 产品结构

- 主屏 ×1：1280×800 世界坐标画布，4 个分区（工作区 / 会议区 / 仓储区 / 展示区）+ 走廊
- 对象 ×27（多）：桌、椅、屏、植、灯、箱 6 类，其中 2 件初始位于走廊 →「未落位」
- 右侧「意图台账」：按分区实时分组列出对象，摆放位置变化即台账变化（落位/移动时 toast 反馈「XX 落入 YY」）
- 底部状态栏：选中对象坐标 / 分区 / 旋转、计数、吸附、缩放

## 验收种子：空间操作有键盘等价物

| 操作 | 键 |
|---|---|
| 移动选中 | ← ↑ → ↓（Shift = 大步 5 格；吸附关时 4px 微调） |
| 循环选择 | Tab / Shift+Tab |
| 全选 / 取消 | A / Esc |
| 复制 / 删除 | D / Del·⌫ |
| 切换类型 | T |
| 旋转 15° | [ ] |
| **发送到分区** | **1 工作区 · 2 会议区 · 3 仓储区 · 4 展示区**（自动找分区内空位，等价于拖拽落位） |
| 新增 | N（类型由工具栏单选决定） |
| 吸附开关 | G |
| 缩放 / 复位 | + − 0（滚轮缩放，空格+拖拽平移） |
| 框选 | 空白处拖拽（Shift 追加） |
| 帮助 | ? |

指针能做的每个空间操作（拖拽移动、拖入分区落位、框选、新增、缩放）都有上表中的键盘等价物。

## 浏览器自检证据

本工作区会话无 shell / 浏览器执行工具（已穷尽 ToolSearch 验证），无法由代理直接截图；
替代方案是**随应用内置的确定性自检**，任何浏览器一键复现：

```
index.html?selftest=1
```

自检通过**真实 keydown 监听器**派发 KeyboardEvent（与人工按键同一路径），
逐条断言：首屏内联就绪（27 对象、台账 5 组）、Tab 选择、方向键位移量（20/格、Shift×5）、
数字键跨分区落位（自动找空位）、D 复制 / Del 删除、T 换型（标签重排 屏-03）、[ ] 旋转、
G 吸附切换后微调步长 4px、A 全选 / Esc、+ − 0 缩放复位、? 帮助浮层。
右上角面板输出每条 ✓/✗ 与汇总（预期 14/14），随后恢复初始布局。
