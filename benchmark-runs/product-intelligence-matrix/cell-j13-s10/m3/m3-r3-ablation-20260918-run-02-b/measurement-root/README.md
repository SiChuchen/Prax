# DimScope · 多维数据探索台

cell-j13-s10（explore × dimensional-space）交付物：单文件静态多维数据探索应用。

## 运行

直接用浏览器打开根目录 `index.html`（支持 `file://` 双击打开）。
零依赖、零构建、零网络请求；合成数据集（2,400 记录 × 10 维度）内联于脚本，**首屏即用，无加载态**。

- 菜单式核验：`screenshots/` 内为真实浏览器（Chrome headless，CDP 真实指针/键盘事件）截图。
- 交互取证脚本：`node scripts/capture.mjs "<chrome.exe 路径>" screenshots`（需 Node ≥ 22）。

## 设计对位

| 简报要求 | 实现 |
|---|---|
| explore × 多维数据，维度切换不重置认知 | 过滤谓词与选中集按**记录 id** 存储于全局 store，与投影 (X/Y/颜色) 解耦；切换维度时原样保留，画布顶部「🛡 上下文保持」回执条显式计数，并有切换提示闪烁 |
| 验收种子：过滤/投影状态有归属且可回退 | **状态账本**记录每次过滤/投影/选中操作：序号 · 时间 · 来源部件（维度卡/画布/图例/键盘/账本/系统）· 动作摘要。支持撤销/重做（Ctrl+Z / Ctrl+Shift+Z）、点击任意快照**跳转回退**（不销毁后续快照，可再前进）、过滤条单条 ✕ 移除 |
| 高维度 | 10 个维度卡（5 数值 + 4 类别 + 1 序数季度），每卡 X/Y/颜色槽位一键切换投影 |
| 高密度 / 无界基数 | Canvas 2D 半透明叠渲 2,400 点；被过滤点淡灰参考层；数值轴 12 分箱微缩分布随过滤实时反馈 |
| 层级性（中） | 产品线 → 品类 两级层级，悬停取样卡展示归属 |
| 静态可开 / 本地运行 | 单 `index.html`，无 CDN/后端/账号/持久化 |

## 交互

- **维度导轨**（左）：点 `X / Y / 彩` 槽位切换投影；数值卡点直方分箱、类别卡点取值即过滤；颜色图例（画布右上）点取值同效。
- **投影画布**（中）：拖拽框选（Shift 叠加）、点选、悬停取样；`A` 全选可见，`Esc` 清除选中，点击空白清除。
- **状态账本**（右）：生效过滤条 + 带归属快照流水，点任意条目跳转回退。

`?demo=` 深链参数可重放与用户操作完全相同的动作序列（见 index.html 内注释），用于分享初始状态与自动化取证。
