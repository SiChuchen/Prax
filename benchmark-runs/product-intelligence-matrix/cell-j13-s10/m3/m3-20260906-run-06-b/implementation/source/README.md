# Prism 多维探索台

**cell-j13-s10（explore × dimensional-space）交付物** —— 单页多维数据探索应用。
主对象：dataset。成功标准：**维度切换不重置认知**。验收种子：**过滤/投影状态有归属且可回退**。

## 打开方式

直接双击 `index.html`（file:// 静态打开即可，无构建、无依赖、无网络请求），或任意静态服务器：
`node evidence/serve.js` → http://127.0.0.1:8123

页面加载完成即处于可用状态：数据（1,280 条确定性记录，种子 20260908）随首屏内联就绪，**不存在加载态**。

## 功能

| 区域 | 能力 |
|---|---|
| 维度轨（左） | 8 个维度（7 类别 + 订单收入分箱）：点名称＝投影，勾选值＝过滤；带基数、活跃过滤徽标 |
| 投影工作面（中） | 当前维度分布条形图（可切度量：收入/数量/利润率；可叠第二维度细分）；过滤后记录表（可排序，列随投影切换） |
| 生效状态托盘（右） | **每条过滤/投影状态**：kind 徽标 + 归属维度 + 取值 + 来源（origin）；孤儿过滤器标注「不在当前投影 · 仍生效」 |
| 回退 | 每条 × 单条回退 · `Ctrl+Z` 撤销 / `Ctrl+Y` 重做 · 全部重置（均可再撤销） |
| 记录明细（右下） | 行点击驱动 contextual inspector；选中跨投影保持；被过滤排除时显示警示；支持按值过滤 |

核心机制（对应设计决策 MC-1/MC-2）：过滤器**按维度持有、与投影正交**——切换投影只改 `store.projection`，永不触碰 `store.filters`；每次变更生成带 id 的状态条目（kind/dim/origin）入托盘并进撤销栈。
