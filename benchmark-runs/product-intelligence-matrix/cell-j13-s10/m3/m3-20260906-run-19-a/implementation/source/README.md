# 棱镜 Prism · 多维数据探索台

cell-j13-s10（explore × dimensional-space）交付物。单页静态应用，无构建、无依赖、无外部服务。

## 运行

直接双击打开根目录 `index.html`（file:// 即可），或任意静态服务器：

```
python -m http.server 8321   # 然后访问 http://localhost:8321
```

首屏即含全量数据：`assets/data.js` 以确定性种子（20260903）同步生成 540 条合成城市观测
记录 × 14 个维度，脚本随页面解析完成，不存在加载态。

## 用户任务映射

| 简报条目 | 实现 |
|---|---|
| explore × 多维数据 | 14 维数据集；左栏维度目录一键切换投影视角（类别→柱图、数值→直方图、序数→有序柱图、高基数→Top-K 折叠） |
| 成功标准：维度切换不重置认知 | 切换投影时保留：全部筛选、排序、撤销历史、列表滚动位置、选中记录锚点；切换后锚点徽标「锚」直接标注该记录在新投影中的组，锚点行持续显示归属 |
| 验收种子：过滤/投影状态有归属 | 顶栏状态账本每个筛选片标注所属维度（维度专属色点 + 维度名 + 实时边际命中数，零命中变警示色）；维度目录行同步计数；操作历史逐条以维度命名 |
| 验收种子：…且可回退 | 四层回退：单片 ✕ 移除 / 维度级清除 / 撤销·重做（Ctrl+Z·Ctrl+Y，历史 80 步）/ 历史列表点击任意步骤时光标回退；全局「重置全部」保留选中锚点 |
| 基数 unbounded | 「名称」维度 540 组投影：Top-24 折叠 + 展开全部，演示单概念→无界数据 |
| 层级性 中 | 大洲 → 分区 两级层次；先筛大洲再投影分区即层级钻取 |
| 密度 高 | 三栏高密度布局：14 维目录 + 全维图表 + 540 行清单 + 全维详情档案 |
| 易变性 中 | 「重采样 ⟳」：新种子再生成数据，状态结构保留，各筛选片命中数即时重校验（失效片警示标注，选中锚点按名称校验身份） |
| 时间性低/空间性无/比较无 | 不做时间刷选、不做地图、不做对照集，聚焦维度认知 |

## 文件

```
index.html        页面骨架
assets/data.js    确定性合成数据集（同步生成，无网络）
assets/app.js     状态机 + 渲染（原生 JS，快照式撤销栈）
assets/style.css  深色高密度主题
```

数据为合成演示数据（mulberry32 种子），字段间带相关性（气候→气温/降水、人口→AQI、
GDP→幸福指数），用于让维度切换呈现可解释的模式。

## 验证（如实记录）

环境说明：本构建会话未提供 shell / 浏览器工具 —— 已按装载契约用 ToolSearch `select:`
验证 `Bash` 与 `mcp__plugin_superpowers-chrome_chrome__use_browser` 均不存在（另有
exec/browser 关键词全文检索为空；两个子代理会话同样无浏览器/shell，codex 代理的工具
清单解析为零）。因此**无法产出真实浏览器截图，本文档不作任何视觉性断言**。

已完成的源码级核验（由独立 QA 代理对全部文件逐行交叉核对）：

- index.html 引用的全部 DOM id 与 app.js 的 `$()` 引用一一对应；两个脚本均为经典脚本、
  加载顺序正确（data.js 先于 app.js），无 fetch/模块/CORS 依赖，file:// 直接打开可用。
- 规模由源码确定：540 条记录（生成循环上界）、14 个维度（DIMS 数组）、初始投影 大洲。
- 首屏无加载态：脚本同步执行，`wire(); renderAll()` 在解析期完成，代码中不存在任何
  加载分支或 spinner。
- 状态机逐行核验：快照式撤销栈（past/present/future，80 步）、单片边际命中计数、
  preserveScroll、选中锚点跨投影重映射、高基数 Top-K 折叠、重采样重校验。
- QA 中发现并已修复：高基数 `hidden` 计数被 `slice` 丢弃、数值分箱二次点击无法取消、
  历史列表与图例折叠按钮未接线、重采样后锚点按 id 误绑另一城市（改为按名称校验）、
  540 组展开时柱宽互相压叠（minW 0.8px）、一处死代码。
- 可复现取证钩子已内置：`window.onerror` 红色横幅 + `document.title` 改写（异常在截图
  与 DOM 转储中直接可见）；`window.__prism` 暴露状态机操作；URL `#scenario=b|c|d` 驱动
  真实交互序列（筛选→选中→维度切换 / 追加撤销 / 追加高基数投影）。在任何有浏览器的
  环境中用 headless `--screenshot` + `--virtual-time-budget=8000` 即可批量取证。
