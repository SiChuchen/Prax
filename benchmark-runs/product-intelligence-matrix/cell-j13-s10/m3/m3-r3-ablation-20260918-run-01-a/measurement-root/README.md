# PRISM · 多维订单探查台

**cell-j13-s10（explore × dimensional-space）** 的交付物：一个从零实现的单文件静态 Web 应用，
用于探查多维数据集——核心承诺是 **维度切换不重置认知**。

## 打开方式

直接双击打开根目录 `index.html`（file:// 即可，无构建、无依赖、无网络请求、无后端）。
数据在脚本同步生成（种子 20260902，2,400 单 × 12 维），页面加载完成即为可用状态——
**不存在任何加载态**。

## 主屏（单屏三栏）

| 区 | 内容 |
|---|---|
| 维度轨（左） | 12 个维度按 层级/分类/序数·分箱 分组；点击 = 切换投影；徽标显示各维过滤占用，圆点显示焦点记忆 |
| 投影台（中） | 当前维度值卡（订单数、度量、占比、顺序量条、客户段构成条）；层级维可「下钻品类 ▸」；明细表（金额降序前 200 行，点击行=选中）；度量切换（销售额/件数/订单数/利润率/评分） |
| 状态账本（右） | 当前投影（含来源+时间）· 过滤账本（逐值 chip，可单删/清空该维）· 选择集（跨维度保留）· 快照历史（点击任意条=时间旅行回退） |

## 验收映射

### user_job：explore 多维数据 → 成功标准「维度切换不重置认知」

- 切换投影（维度轨点击 / 下钻）只改聚合轴；**选择集、过滤、各维焦点记忆全部保留**，
  顶栏 pill 与认知栏实时显示保留量；切换瞬间 toast 播报保留结果；
  回到曾查看过的维度时自动滚回并闪烁其焦点值卡。
- 选中项若被后续过滤排除，不出现在明细表但仍在选择集中，并标注「在范围外，仍保留」。

### 验收种子：过滤/投影状态有归属且可回退

- **归属**：每次过滤/投影/度量/选择变更都写入快照账本，记录 动作标签 + 来源
  （值卡点击 / 明细行点击 / 维度轨 / 下钻 / 度量切换 / 账本 / 时间旅行 / 系统）+ 时间戳；
  过滤 chip 与投影卡均展示其来源。
- **可回退**（四条互不排斥的路径）：
  1. 逐值回退：过滤 chip 上的 ✕；
  2. 维度级回退：「清空该维」；
  3. 撤销/重做：顶栏按钮或 Ctrl+Z / Ctrl+Shift+Z；
  4. 时间旅行：点击快照历史任意条，恢复到该时刻完整状态（并记为新快照，仍可继续撤销）。
  「重置全部」本身也是一次可撤销的记账动作。

## 信息形状对策（shape 束）

- 基数 unbounded：聚合优先（值卡=全量聚合），明细封顶 200 行并标注 1/n；
- 维度性 高 / 密度 高：12 维常驻左轨，值卡一屏数十个且每卡含 5 类信息；
- 层级性 中：部门→品类 两级层级，「下钻」= 范围过滤 + 投影切换（双双入账、可回退）；
- 关系性 中：值卡内嵌客户段构成条，建立值-段关系视图；
- 时间性 低：月份仅作一个可投影维度，不做时间轴叙事；
- 比较/空间性 none：不设对比模式与地图。

## 视觉规范

VIP=青 `#199e70`、企业=黄 `#c98500`，从不循环），度量条用蓝 ramp 单色顺序编码，文字一律用墨色

## 浏览器证据

`evidence/` 目录由真实 Chromium（headless Edge/Chrome）对本页截图产生，四个场景：

| 文件 | 场景 | 期望断言（页面 console 输出 `[evidence:*]`） |
|---|---|---|
| 01-initial.png | s1 首屏即用 | 快照 #1，无过滤、无选中 |
| 02-filter-select.png | s2 过滤「品类=护肤」+ 选中 2 行 | filters=cat:c9 selection=2 |
| 03-dimension-switch.png | s3 切换投影→渠道 | **selection=2、filters=cat:c9 原样保留**（认知未重置） |
| 04-time-travel.png | s4 时间旅行回快照 #4 | 过滤/投影/选中恢复到该快照状态 |

`console.log` 同时记录每次快照提交（`[prism] 快照#n 标签 (来源)`），可作为「归属」的机器可读证据。
（截图方式：Chrome 152 `--headless=new --virtual-time-budget` 驱动，场景内交互通过真实 DOM click 事件走应用自身事件路径。）

**实测记录（2026-09-24，file:// 直开，无 JS 错误）**：

```
[evidence:s1] projection=cat     filters=-       selection=0 rows=2400 snapshot=1/1
[evidence:s2] projection=cat     filters=cat:c9  selection=2 rows=98   snapshot=4/4
[evidence:s3] projection=channel filters=cat:c9  selection=2 rows=98   snapshot=5/5   ← 切维后认知原样保留
[evidence:s4] projection=cat     filters=cat:c9  selection=2 rows=98   snapshot=6/6   ← 时间旅行回 #4（快照 #6=回退至 #4）
```

s2→s3 对比即成功标准的机器证明：投影从品类切到渠道，过滤（cat:c9）、选择集（2 项）、
范围（98 单）逐项不变；截图 03 中 toast 与账本同屏可证。四张截图均已人工查验
（无标签碰撞、变暗值卡仍可读、选中行高亮跨投影保持）。
