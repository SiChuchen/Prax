# 实体目录管理台 — cell-j01-s01（manage × entity-hierarchy）

单页 Web 应用：管理大量有层级归属的结构化实体，批量操作**零误伤**、状态归属**显式**。

## 运行

无构建、无依赖、无网络请求。两种方式任选：

- 直接双击打开根目录 `index.html`（经典脚本，`file://` 可直接运行）；
- 或起本地静态服务：`python -m http.server` / `npx serve` 后访问根路径。

页面加载完成即数据就绪（214 条实体随首屏内联渲染，无加载态）。

## 功能

- **层级树导航**：域 → 类别 → 子类别；节点带「直接·累计」计数与五状态分布微条；点击划定为表格范围（含子层级）。
- **高密度实体表格**：214 条实体，列排序、关键字搜索（`/` 聚焦）、状态筛选 chip（带全局计数）、行内展开详情、Shift 范围加选、表头三态全选。
- **显式选择集（零误伤核心）**：选择集独立于筛选与导航，仅四种显式动作可变（行复选 / 范围全选 / 清空 / 仅保留可见）；「选当前筛选结果」与「选子树全部」按钮均标注计数；已选项被筛选隐藏时出现警示条并可展开核对、一键裁剪。
- **批量操作**：改状态 / 移动类别 / 加标签 / 移除标签 / 删除。全部先弹**逐项预览模态**：每行显示 编码、名称、归属路径、变更前后对照；无变更项单列并自动跳过；确认按钮实时显示将生效条数；删除需显式勾选确认。
- **零误伤契约（实现层保证）**：`computeAffected()` 是预览与执行的唯一共同计算——确认列表与实际作用集合逐 id 一致。
- **操作回执与撤销**：提交后状态栏显示回执 + 单步撤销（删除同样可精确恢复，快照含全字段）；「操作记录」弹层留痕全部操作。
- 键盘：`/` 聚焦搜索、`Esc` 关闭模态；树与表格均为单 Tab 停留点 + 方向键巡航（roving tabindex），空格选行、回车展开、左右键展开/收起子树；焦点可见（`:focus-visible`）。

## 结构

```
index.html      单屏入口
css/styles.css  紧凑专业工具视觉（13px、状态五色令牌）
js/data.js      种子数据（固定种子确定性生成，内联就绪）
js/app.js       应用核心（状态属主：selection/query/mode/viewport 各一）
evidence/       真实浏览器截图证据（无头 Edge，1680×950）
```

URL 参数 `?scene=selected|preview|delete|detail|receipt|undo|selftest` 仅用于自动化取证复现交互状态（走的是真实代码路径；`selftest` 会派发真实 DOM 事件跑 12 项断言并在页内输出结果），正常使用无需理会。

## 质量实测

- `prax-measure`（Playwright 实测，1680×950）：7/7 通过 —— layout.overflow / layout.responsive_collision / text.truncation / a11y.contrast / a11y.focus_order / a11y.target_size / type.min_projected_size，回执绑定当前实现（implementation_current）。
- 页内自测（真实 DOM 事件）：12/12 通过，含零误伤守恒断言（已选 42 = 生效 35 + 跳过 7；执行后计数交叉核对；撤销精确恢复）。
- 证据：`evidence/`（8 张真实浏览器截图 + 2 份渲染 DOM 快照）。

## 设计决策映射（Prax 会话 ds_20260908150819_48cc0e7b）

| 简报/决策 | 落点 |
|---|---|
| PAT-DATA-EXPLORER | 左树（overview）+ 中表格（dense data surface）+ 选择驱动操作条 |
| mc-selection-model | 选择集与筛选解耦 + 隐藏已选警示条 |
| mc-select-all-scope | 「选当前筛选结果 / 选子树全部」双按钮带计数 |
| mc-preview-modal | 逐项受影响清单 + before→after 对照 + no-op 跳过 + 删除勾选确认 |
| mc-undo | 单步撤销 + 操作记录（删除可恢复） |
| n-persist（gap，显式取舍） | 会话内存态，刷新重置为种子数据；状态栏已注明 |

## 数据持久化说明（简报边界内的显式取舍）

按交付约束「不要求后端、账号体系或持久化服务」，应用为纯会话内存态：刷新后重置为种子数据。状态栏右下有常驻提示。
