# AssetGrid · 设备资产批量管理台

cell-j01-s01（manage × entity-hierarchy）交付物：从零实现的单页 Web 应用，管理
「大区 › 城市 › 门店 › 设备」四级层级下的结构化实体集合（59 台设备 / 17 个分组）。

## 运行

零构建、零依赖、零网络请求。直接用浏览器打开：

```
index.html        ← 双击即可（file:// 可用），或任意静态服务器指向本目录
```

页面加载完成即为可用状态：全部种子数据内联于 `js/data.js`，随首屏同步渲染，无加载态。

## 验收点 → 实现映射

验收种子：**批量选择与操作零误伤，状态归属显式**

| 验收点 | 实现 |
|---|---|
| 批量选择零误伤 | 分组勾选范围显式二选一（仅直属 / 含子孙）；选择集逐台可拆（右侧 chip 逐台移除）；表头全选只作用于「当前筛选可见行」 |
| 批量操作零误伤 | 每次批量操作先出**确认单**：逐台列出受影响设备与变更前后对比，可逐台取消勾选；CTA 按钮实时显示精确台数 |
| 保护机制 | 设备可标记 🛡 受保护；批量写操作默认跳过受保护设备，需显式勾选「本次包含」才会纳入 |
| 状态归属显式 | 每行同时呈现「自身状态」（跟随上级 / 四种状态，点击可单台设置或清除覆盖）与「生效状态 · 归属」（自身设定 / 继承 · 某分组（含策略备注）/ 系统默认） |
| 分组策略级联 | 分组可设状态策略（●/○ 按钮），弹窗内给出**影响预览**：将改变哪些设备的生效状态、哪些因自身状态或更近策略而不受影响 |
| 操作可追溯 | 全部批量/单台/策略变更写入操作日志（逐台 before → after 明细）；支持一键撤销最近一次事务（含删除恢复） |

## 文件

```
index.html      单屏入口
css/styles.css  样式
js/data.js      内联种子数据（状态模型 / 分组树 / 设备清单）
js/app.js       应用逻辑（状态、渲染、事务与撤销）
evidence/       验证记录（探测过程、逐检查点期望画面、无头截图命令）
```

另支持深链锚点 `#s=2…7`，免点击直达各操作状态（选择 / 确认单 / 结果 / 策略预览 / 继承视图 / 日志），见 `evidence/README.md`。
