# 目录矩阵 · 商品层级管理台

cell-j01-s01（manage × entity-hierarchy）交付物：管理大量有层级归属的结构化实体集合，
成败点为**批量操作零误伤**与**状态归属显式**。

## 运行

纯静态、零构建、零依赖，数据随首屏同步内联（`data.js` 固定种子确定性生成，非加载态）：

- 直接双击打开 `index.html`（file:// 协议即可用）；或
- `python -m http.server 8000` 后访问 `http://localhost:8000`。

无后端、无账号、无外部服务；会话内操作留痕于内存，「重置演示」一键恢复初始快照。

## 功能 → 验收映射

| 验收点 | 实现 |
|---|---|
| 批量选择零误伤 | 行 / 品类组 / 事业部 / 全库四级显式勾选，三态（全选/半选/未选）；选择跨筛选持久；被筛选或收起隐藏的已选条目以顶部琥珀警告条显式披露（列出 SKU、可一键「仅保留视图内」），绝不静默扩大或丢失选择 |
| 批量操作零误伤 | 每次批量操作先弹**影响预演**：将执行/跳过/拦截三类计数 + 按归属路径分组的逐条清单（含状态 before→after）；已达目标状态自动列为跳过；删除受「在售保护」拦截（在售须先下架），且需勾选「已逐条核对」；执行后 toast 给出 成功/跳过/拦截 结果并支持一键撤销 |
| 状态归属显式 | 每行常驻「归属路径」列（事业部 › 品类）；SKU 编码内嵌组织代码；操作日志全量留痕（影响清单 + 跳过/拦截明细逐条可展开）；商品详情页显示归属面包屑与该商品近期操作 |

数据规模：4 事业部 → 14 品类 → 151 商品；状态：在售 / 已下架 / 草稿 / 待审核。

## 文件

```

app.js       选择模型 / 预演确认 / 执行与撤销 / 审计日志
evidence/    真实浏览器截图（headless Chrome, 1680×1050）
```
