# TreeLedger · 设备资产批量管理台

**cell-j01-s01 · manage × entity-hierarchy** · product-intelligence-matrix §43

层级实体集合的批量管理单页应用：4 区域 → 12 系统 → **138 台设备** 三级层级，
围绕两条验收主线构建 —— **批量操作零误伤** 与 **状态归属显式**。

## 运行

零依赖、零构建、零外部服务。双击 `index.html`（file:// 直接可用），
或 `python -m http.server` 后访问。页面加载完成即处于可用状态：
种子数据由 `data.js` 同步内联，首屏即渲染 138 条设备与完整层级树，无加载态。

## 验收种子 → 功能对照

**批量选择与操作零误伤：**

- 勾选组节点 = 显式选中其全部后代，批量条分开计数：
  `已选 29 项 = 设备 27 台（按状态分布）＋ 组织节点 2 个（其下设备已计入，节点本身不改动）`
- 批量改状态 / 删除前强制预览：**逐台枚举** 所有受影响设备（编码 / 名称 / 归属系统 / 旧状态 → 新状态），
  并明确标注 `全库共 138 台，未列出的 N 台不受任何影响`
- 「全选可见」只作用于当前搜索 / 筛选 / 范围命中的行，按钮文案随状态切换
- 删除仅作用于设备叶子；区域 / 系统节点不会被删除（弹窗中显式声明）
- 每次批量操作生成操作记录，支持一键**撤销**（精确回滚每台设备的旧状态；删除亦可撤销恢复）

**状态归属显式：**

- 每台设备携带完整**归属路径**列（区域 / 系统），层级树展示区域→系统→设备归属与台数汇总
- 设备状态（运行 / 维护 / 停用 / 待报废）行内可见可改，单台修改同样入操作记录、可撤销
- 顶部实时统计按状态汇总；批量条按状态细分已选设备
- 操作记录逐条记载时间、动作、受影响设备编码清单（首 3 条 + 总数），未撤销的最近操作可撤销
