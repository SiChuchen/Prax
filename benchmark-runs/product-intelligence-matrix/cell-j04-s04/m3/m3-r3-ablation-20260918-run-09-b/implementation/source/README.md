# 脉墙 PulseWall — 易变指标监控（cell-j04-s04）

`monitor × volatile-evidence-stream` 的单页实现：一面恒定位置的指标瓦片墙，
异常在扫视内可见，任何变化都可逐点追溯，更新无闪烁噪声。

## 运行

无构建、无依赖、无后端。两种方式任选：

- **直接打开**：双击 `index.html`（file:// 协议即可完整运行）
- **本地服务**：`python -m http.server` 或 `npx serve` 后访问根路径

页面加载即处于 ready 态：24 个指标（4 分组 × 6）连同各自 90 点带时间戳的
历史一次性内联生成，随首屏渲染；不存在加载态。

## 操作

| 操作 | 方式 |
|---|---|
| 扫视异常 | 危急=红、告警=琥珀的左色条 + 徽标 + 分区计数；位置恒定，颜色扫描即可 |
| 追溯变化 | 点选（或 Tab+Enter）任一瓦片 → 右侧 inspector：90 点轨迹图（异常段高亮 + 阈值线）、异常起始时间与持续时长、最近 12 点逐点采样明细 |
| 跨指标追溯 | 底部异常事件流（最近 8 条，时间戳化），点击指标名跳转 |
| 收窄扫视 | 顶部严重度（全部/危急/告警）与分组过滤；过滤采用**置灰保位**，不重排 |
| 定格读数 | `空格` 暂停/恢复数据流；`Esc` 关闭 inspector |

## 设计要点（对应验收种子"指标变化可追溯，无闪烁噪声"）

- **无闪烁**：所有瓦片 DOM 一次性创建、位置恒定；每个采样 tick（1.2s）只做
  `textContent` / 类名 / SVG path `d` 的就地替换；等宽数字字体
  （`tabular-nums`）保证数字跳动不移位；除心跳点 CSS 脉动外无任何动画，
  且尊重 `prefers-reduced-motion`。
- **可追溯**：每指标维护 90 点环形缓冲（值 + 时间戳）；状态迁移逐点重放为
  事件（与轨迹严格一致）；inspector 给出异常起点、持续时长、异常段高亮与
  逐点 Δ。
- **首屏即 ready**：确定性种子（mulberry32）同步生成初始历史，其中脚本化
  剧本保证首屏存在 2 危急 + 4 告警，事件流预填，inspector 预选最近一次
  危急异常。`node test\smoke.js` 可复验（不依赖浏览器）。

## 结构

```
index.html   壳与静态骨架
styles.css   紧凑暗色主题（设计 token 在 :root）
data.js      指标目录、种子随机源、初始历史剧本、流推进与事件模型
app.js       一次性 DOM 构建、就地更新、选择/过滤/暂停、键盘
test/smoke.js  数据引擎冒烟测试（Node 直跑）
```

状态所有权：mode→流引擎；query→顶部过滤；selection→墙+inspector。
规模：单主屏，无路由、无后端、无持久化、无外部服务。
