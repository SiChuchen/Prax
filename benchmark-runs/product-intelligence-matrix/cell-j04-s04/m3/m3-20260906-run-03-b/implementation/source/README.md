# Pulsewall — 易变指标监控（cell-j04-s04）

monitor × volatile-evidence-stream 单页应用：一面 **状态瓷片墙** 监控 48 个易变指标
（6 服务 × 8 指标），异常在一次扫视内可发现，且每次变化**可追溯**。

## 打开方式

零依赖、单文件、无构建：

- 直接双击 `index.html`（file:// 可用），或
- 任意静态服务器，如 `python -m http.server` / `npx serve`

页面加载首帧即为 **ready 态**：150 拍历史在脚本内同步预生成（含 2 个持续严重、
3 个持续警告异常与若干已恢复的历史事件），无加载门。

## 交互

| 操作 | 方式 |
|---|---|
| 发现异常 | 耐久状态色（左缘+底色+徽标）+ crit→warn→normal 置顶排序；顶部计数徽标 |
| 追溯变化 | 点击瓷片 → 检查器：完整折线 + 阈值线 + 事件标注 + 逐条事件（时刻、前后值） |
| 全局事件流 | 右侧事件轨；勾选「仅看选中指标」按选中过滤；点击事件行选中其指标 |
| 过滤 / 搜索 | 顶部状态 chips（兼计数）；`/` 聚焦搜索，Esc 清除 |
| 暂停 / 恢复 | 顶栏按钮（冻结推进，不丢上下文） |
| 键盘 | 方向键巡览瓷片，Enter 选中，Esc 关闭检查器 |

## 无闪烁纪律

- 数字 `tabular-nums` 等宽、小数位固定 → 数值更新零跳动
- 瓷片结构不重建，仅文本/类名/canvas 原地更新；重排走 FLIP（300ms transform 过渡）
- 事件轨新行顶部插入并补偿 scrollTop，不推挤主墙
- 状态为**持续**视觉编码（无闪烁动画）；数据 1s 一拍，渲染批量

## 参数（URL query，均可选）

`?seed=20260908` 确定性随机种子 · `?speed=毫秒` 节拍间隔 · `?paused=1` 初始暂停 ·
`?select=<指标id>` 预选中指标（如 `select=gw.5xx`）

## 已知妥协

流为本地模拟（内联种子 + 节拍生成器），历史与事件仅存于会话内存，刷新即重置——
简报不要求持久化服务（Prax 能力对账 N6，显式妥协）。
