# PulseWatch · 指标流监视台

cell-j04-s04 · monitor × volatile-evidence-stream · product-intelligence-matrix

面向「易变指标流监视」的单页 Web 应用：异常在扫视内可见（告警条 + 状态着色 + 阈值带），
任何指标变化可追溯（事件流 / 单指标状态变化史 / 曲线事件标记），且无闪烁噪声。

## 运行

直接双击打开 `index.html`（file:// 即可，无构建、无外部服务、无网络请求）。
或任意静态服务器：`python -m http.server` 后访问根路径。

- 主屏 1 个：指标网格（4 域 × 28 指标）+ 事件流 + 指标追溯面板
- 首屏即用：240 个历史样本（8 分钟）随脚本同步内联生成，首帧即完整可用，无加载态

## 交互

| 操作 | 说明 |
|---|---|
| 点击卡片 / 事件行 | 选中指标 → 右下追溯面板：全量曲线（阈值线 + 事件标记）、5min 统计、状态变化史 |
| 域筛选 chips / 仅看异常 | 过滤网格；「仅看异常」隐藏全部正常卡片 |
| 暂停 / 速度 1×2×4× | 控制模拟流节奏（采样间隔恒定 2s） |
| `?select=<metric.id>` | 深链直达某指标的追溯视图 |

## 验收种子 ↔ 实现映射

**指标变化可追溯**
- 全局事件流：每次状态变化一行（时刻、转移、当时值），最新在顶，可点击回跳
- 单指标状态变化史：本会话内该指标全部转移按时间回放
- 曲线事件标记：追溯图表上以纵向刻痕 + 三角标出每次变化的时刻与级别
- 告警条 chip 显示当前值 + 状态持续时间（持续 mm:ss）

**无闪烁噪声**
- 阈值判定带滞后：连续 2 样本越界才触发，连续 3 样本回带内才恢复 —— 单点毛刺不产生状态抖动
- 网格定序不重排：卡片顺序永不变化，更新只改 textContent 与 canvas 重绘，零布局位移
- 等宽数字（tabular-nums），数值不跳宽；入场/脉冲动画均为一次性，且尊重 `prefers-reduced-motion`

## 结构

```
index.html   页面骨架（单屏）
styles.css   暗色控制台主题、状态色系统（正常/警告/严重 × 4 域色）
app.js       指标目录、种子随机游走模拟器、事件剧本、滞后状态机、canvas 渲染
```

模拟流为确定性种子（mulberry32，按指标 id 播种），内置事件剧本：载入即有
1 严重 + 2 警告进行中；载入后 ~21s 副本同步延迟爆发为严重、~54s 检索延迟漂移、
~96s Redis 命中率下探……持续演示 发现→升级→恢复 全生命周期。
