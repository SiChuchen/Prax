# Meridian 变更时序档案 · cell-j06-s06

**understand × temporal-sequence** —— 单页 Web 应用：理解一个支付网关生产环境
5 个工作日内的 29 条变更/观测记录，让「随时间演化的状态」的**变更因果可读**。

## 运行

直接双击打开 `index.html`（或任意静态服务器指向本目录）。无构建、无依赖、
无网络请求；初始数据内联在 `index.html` 中，页面加载完成即处于可用状态
（无加载态）。

生成真实浏览器截图（可选）：`powershell -ExecutionPolicy Bypass -File shots.ps1`
（输出到 `shots/`，本仓库已包含一次真实运行的产物）。

## 主屏（1 个）

- **时间线**（左）：29 条记录严格按时间升序、按天分组；卡片带类型色点、
  严重级标签；组件/类型筛选后以「⋯ 已按筛选隐藏 N 条（时段）⋯」标记时间缺口，
  被选记录的因果链成员即使命中筛选反义也保留并标注「链路保留」。
- **因果链路条**（左上）：选中记录的全部上游根因 → 自身 → 下游结果，
  按时间线性化，节点可点击跳转。
- **记录详情**（右上）：变更前 → 变更后/观测 对照表、评估缺失等注记、
  上游因果 / 下游结果（可点击）。
- **状态回放**（右下）：滑杆按时间顺序重放每条 `set` 操作，展示任意时刻
  各组件的派生状态；最近一条变更写入的字段高亮并标注来源记录与时刻；
  提供「下一条 ▸」快进。
- **时序校验徽章**（页头）：加载时校验①记录时间严格有序 ②全部因果边满足
  「因先于果」，结果常显：`✓ 29/29 有序 · 24/24 因果一致`。

验收种子「时间结构与变更语义一致」的落点：因果边单向指向前方时间
（校验徽章强制）、状态 = 按时间序折叠变更的纯函数（回放面板）、筛选不破坏
时间结构（缺口标记 + 链路保留）。

数据为虚构演示档案：3 起事件（缓存 TTL → 回执风暴；DDL 锁 → 提交延迟；
开关跳灰度 → 手续费少收）均含完整「变更 → 观测 → 应急 → 恢复 → 复盘行动」
因果链，含跨日长链（c02 → c07 → c27）。
