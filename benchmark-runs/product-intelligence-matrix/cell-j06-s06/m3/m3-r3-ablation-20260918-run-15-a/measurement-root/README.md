# Ledgerline · 变更集回放台

cell-j06-s06 · understand × temporal-sequence · 主对象 **change_set**

一个单页静态应用：把一个订单服务 36 小时窗口内的 **42 条变更**（发布 / 配置 / 开关 / 告警 / 操作）
放在同一条时间轴上回放。因果边恒由「早」指向「晚」，游标扫过时右侧重建**该时刻的系统状态**
（版本、连接池、灰度比例、激活告警、所处阶段），底部三联小倍数曲线与游标联动——
**时间结构与变更语义一致**这一验收种子，被同时做进数据（加载即时序校验）、视图（泳道 + 阶段带 + 因果高亮）
与交互（回放 = 状态重建）三层。

## 打开方式

无需构建、无需服务：直接双击打开根目录 `index.html`（file:// 可用），或任意静态服务器。
首屏数据全部内联于 `js/data.js`，页面加载完成即为可用状态，无加载态。

## 主屏

| 区 | 内容 |
|---|---|
| 顶栏 | 变更集元信息、变更/因果边计数、**时序校验徽章**（加载时校验全部 33 条边 cause.t < effect.t）、回放控制（播放/速度/时刻/全窗） |
| 左栏 | 变更类型图例（点击过滤，形状为色觉无关的次级编码）、阶段列表（点击聚焦该时间带） |
| 中屏 | 主时间轴：5 组件泳道 × 阶段带，节点形状×颜色双编码类型，贝塞尔因果边（选中即高亮整个上游因/下游果传导网），可拖拽回放游标、滚轮缩放/平移 |
| 右栏 | **时刻状态卡**（游标处状态折叠重建 + 激活告警）、**变更详情卡**（载荷 before→after、直接因/果可点击跳转） |
| 底栏 | 指标小倍数 ×3（p99 延迟 / 错误率 / 缓存命中率），与时间轴共享 x 视窗与游标 |

交互：空格播放/暂停；←/→ 跳上一/下一条变更；拖动任意处回放；滚轮缩放（Shift+滚轮平移）。
URL 参数支持确定性取证：`?t=<小时>` `?sel=<变更id>` `?phase=<p1..p5>`。
