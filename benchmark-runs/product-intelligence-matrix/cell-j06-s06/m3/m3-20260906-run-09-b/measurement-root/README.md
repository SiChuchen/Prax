# Orbit CDN · 变更时间线（cell-j06-s06 · understand × temporal-sequence）

单页只读应用：沿时间线理解一个随时间演化的系统状态（`change_set` 序列），
读出每次变更**改了什么**、**因何发生**、**引发了什么**，并在任意变更集时刻
查看**状态回放**。

## 运行

无构建、无依赖、无网络请求：

- 直接双击打开 `index.html`（`file://` 协议即可）；或
- 任意静态服务器，如 `python -m http.server 8000` 后访问
  <http://localhost:8000/>。

页面加载完成即处于可用状态（数据内联于 `data.js`，随首屏渲染，无加载态）。

## 操作

| 操作 | 效果 |
|---|---|
| 点击时间线节点 | 选中该变更集，右侧详情与状态快照随之更新 |
| 点击 `↩ 因 cs-xx` / `↪ 果 cs-xx` 徽标 | 跳转并高亮对端变更集（因=更早、果=更晚） |
| 类型 chips / 元素下拉 | 筛选变更明细（结构置灰保留，顺序不变） |
| `↑` / `↓` | 沿时间序移动选中（上=更早，下=更晚） |
| `Esc` | 清除筛选 |

## 设计要点（验收种子：时间结构与变更语义一致）

1. **序即真**：时间线节点顺序 = 数据时间序（严格递增，启动时校验）。
2. **因果不逆时**：`data.js` 中每条因果链接满足 `cause.ts < effect.ts`
   （启动时校验，违规将横幅告警）；徽标方向（↩ 上指更早 / ↪ 下指更晚）与
   时间轴方向同构。
3. **回放由构造保证一致**：状态快照 = 按时间升序逐条应用 change 至选中
   节点（含）的纯函数，与时间轴共用同一排序，不存在第二份存储的状态。
4. **状态覆盖**：ready（首屏即就绪）/ selected（选中高亮 + 因果对端描边）/
   empty（筛选无匹配：结构置灰 + 横幅 + 清除入口）/ error（渲染异常横幅）。
   按交付约束不存在加载态。

## 文件

- `index.html` — 单屏骨架（顶栏 / 筛选 / 时间线 / 选中详情 / 状态回放）
- `data.js` — 内联数据集：Orbit CDN 发布列车 R2026-35（8 变更集 · 18 条变更 · 7 条因果链接 · 10 个元素）
- `app.js` — 排序校验、回放纯函数、渲染与交互
- `styles.css` — 深色专业主题（regular 密度，时间线为主导区）
