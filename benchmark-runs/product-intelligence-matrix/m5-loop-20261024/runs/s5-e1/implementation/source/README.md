# ExoLens — 系外行星多维探索台

cell-j13-s10（explore × dimensional-space）· product-intelligence-matrix

单页、单屏、零依赖、零网络请求的多维数据探索工作台。

## 运行

**直接双击打开根目录 `index.html` 即可**（`file://` 静态打开，无需服务器、无构建、无外部服务）。
页面加载完成时即处于可用状态：480 条数据与全部维度定义内联在文件内，同步初始化，首帧即为就绪态（无加载态）。

## 是什么

一个「投影探索台」：

- **维度架（左）**：12 个维度（4 分类 + 8 数值）。可展开按值勾选过滤、设数值范围过滤，或一键把维度装入投影通道。
- **投影画布（中）**：canvas 全量散点。X / Y / 颜色 / 尺寸四个通道各绑定一个维度——**换维度即换镜头**：轴范围稳定、过滤与选中原样保留、顶栏闪现「上下文已保留」。支持悬停提示、点选、框选、框选转过滤、表格视图。
- **记录检查器（右）**：选中记录的全维度明细与同恒星系上下文（层级）；多选时给出类别构成小条形。
- **状态轨迹（底）**：每一步过滤 / 投影 / 选中操作都是一枚 chip，**归属三元组（来源控件 → 目标维度 → 取值）**，点击 chip 展开完整归属详情，并支持三种回退粒度：
  1. 单条 **禁用 / 启用**（不销毁历史）；
  2. 全局 **撤销 / 重做**（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z，Esc 清除选中）；
  3. **回退到任意步**（点击历史 chip 直达；未来步骤可「前进到此步」，全部回退后仍可重做）。

空结果（过滤过严）提供「回退上一步 / 全部回退」出口；初始化异常与运行时错误显示错误横幅（错误态）。

## 数据

内联合成快照（seed=20260902，480 条，确定性可复现），域模型对齐真实系外行星目录的形状：
无界目录（真实目录数千条且持续增长）、高维（12 维）、中层级（行星 → 恒星系；任务 → 仪器）、高密度散点。
`tools/gen-data.mjs` 可独立重放同一数据集到 `src/data.json` 用于核对（应用本身不依赖 Node）。

## 设计依据（Prax 设计会话 ds_20261024181435_3fb05d73）

- 结构：PAT-DATA-EXPLORER × Contextual Inspector（Overview-Filter-Detail + Orientation Invariants）。
- 成功标准「维度切换不重置认知」的实现机制：投影状态与过滤 / 选中状态分属独立语义，通道切换只写投影；轴范围为全域稳定轴。
- 验收种子「过滤 / 投影状态有归属且可回退」：状态轨迹 chip（来源 + 目标维度 + 取值）+ 禁用 / 撤销重做 / 回退到任意步。
- 可视化遵循 dataviz 参考色板（dark 表面已验证的固定槽位顺序），散点 all-pairs 场景下类别身份以形状作次级编码，文本一律用墨色 token。
- 无障碍：原生控件 + aria 状态（pressed / expanded / live）、:focus-visible 焦点环、动态画布 aria-label、表格视图作为图表的无障碍备选。
