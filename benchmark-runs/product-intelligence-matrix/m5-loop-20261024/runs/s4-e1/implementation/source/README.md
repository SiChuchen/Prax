# 发布执行台（Runway）

单页 Web 应用：引导发布值班长**零失误走完**一个高后果生产发布流程（runbook RB-2027-042 · v2.7.0）。
对应基准格 cell-j10-s09（complete × consequential-flow）：单一高后果流程、阶段→步骤高层级、
不可逆步骤必须有**确认路径 + 恢复路径**。

## 运行

- 直接双击打开根路径 `index.html`（纯静态、无构建、无外部服务；file:// 与本地 http 均可）。
- 可选：`python -m http.server 8000` 后访问 `http://localhost:8000/`。

页面加载完成即处于可执行状态：全部流程数据内联于 `data.js`，脚本同步渲染首屏，**无加载态**。

## 产品结构（主屏 1 个）

| 区域 | 内容 |
|---|---|
| 顶栏 | 流程标识、版本、变更窗口、全局进度（x/17 步） |

| 中栏 | 当前步骤执行卡：操作指令、异常分支（若…则…）、验证门（逐项断言勾选，全过解锁完成）、不可逆风险横幅、**恢复路径子区（执行前后常驻）** |
| 右栏 | 执行日志：时间戳 + 类型徽标（常规/验证/不可逆/恢复），不可逆与恢复事件高亮，可跳回对应步骤 |
| 右下 | 导出纪要（txt 下载）、重置演练 |

## 防失误机制（零失误走完全程）

1. **顺序强制**：pointer 状态机（idx < pointer 完成 / = 当前 / > 锁定），结构上不存在可跳步状态。
2. **验证门**：8 个验证步骤须逐项勾选断言，未全过无法完成。
3. **确认门**：3 个不可逆步骤（数据库迁移 MIGRATE-0042 / 全量切流 CUTOVER-100 / 清理旧实例 RETIRE-V269）
   须键入确认短语；短语不匹配呈错误态且按钮禁用。
4. **恢复路径**：每个不可逆步骤内置具体回滚指引；执行后入口保持可用——ROLLBACK 短语确认后
   流程回退至该步骤待重做、后续步骤重锁并重置验证门、日志记录恢复事件。恢复是真实可走的路。
5. **留痕**：全程操作日志 + 一键导出发布纪要（txt）。
