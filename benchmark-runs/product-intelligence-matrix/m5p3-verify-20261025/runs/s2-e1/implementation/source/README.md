# 棱镜 Lens · 多维数据探索台

**cell-j13-s10 · explore × dimensional-space**（product-intelligence-matrix，priority-1 §43）

单页 Web 应用：对一张 520 条 × 10 维度的开源仓库观测集做连续维度探索。切换投影 / 着色 / 过滤维度时**不重置认知**，且**过滤/投影状态有归属（来源维度芯片）且可回退（撤销 / 重做 / 轨迹跳转 / 一键回全集）**。

## 运行

- **直接打开**：双击 `index.html`（`file://` 协议即可，零依赖、无构建、无外部服务）。
- 或起本地静态服务：`npx serve .` / `python -m http.server`。
- 交互取证脚本（可选，需本机 Chrome + Node ≥22）：`node scripts/cdp-evidence.mjs`，产物在 `screenshots/`。

## 交付形态

```
index.html          入口（静态可开）
css/styles.css      设计 token 与样式（compact 密度、AA 对比、信号高于装饰）
js/data.js          内联数据集：确定性 PRNG（mulberry32, seed=20260925）→ 520 条 × 10 维度，
                    随页面同步解析执行，无 fetch、无加载态，首帧即就绪
js/app.js           单一视图状态所有者 + 快照历史 + 定向不变量渲染
screenshots/        真实浏览器截图证据（无头 Chrome）
scripts/            CDP 交互取证驱动（零依赖 Node 脚本）
```

## 设计实现映射（Prax 会话 ds_20261025123811_24938c24）

| 决策 | 实现 |
|---|---|
| Pattern：Data Explorer × Contextual Inspector（L2 已查证） | 主导区=当前维度分布图（`data-region="data"`）+ 稳定顺序台账（`collection`）+ 检查器（`detail`）+ 维度面板 + 状态归属条 |
| 维度切换不重置认知（成功标准） | 四类定向不变量：①区域恒定——切换只重投影，区域/全域坐标轴不动；②选择保持——`selectionId` 跨任何视图变更存活，图中 ◆/虚线锚点跟随；③顺序稳定——台账按稳定 id 排序，被过滤行淡出保留不重排；④颜色语义——每分类维度取值色板一次性注册，会话内恒定 |
| 过滤/投影状态有归属 | 状态条芯片逐条标注来源维度与当前值（投影/着色/过滤三类），过滤芯片可单条移除 |
| 可回退 | 全部投影/着色/过滤变更经 `commit()` 入快照历史：Ctrl+Z 撤销、Ctrl+Shift+Z / Ctrl+Y 重做、轨迹条点击时间旅行、⟲ 回到全集；空结果面板提供回全集出口 |
| 首屏即就绪 | 数据内联同步渲染，无加载态；空态/选中态/错误态（初始化失败面板）齐备 |
| unbounded 形状 | 分类投影条形聚合 + 数值直方图分箱（全域轴）+ 逐条记录条带 + 台账滚动承载，不假设有限值集 |

## 数据说明

演示数据集 `OSS Radar 520` 由确定性 PRNG 生成（同种子恒产出同一数据），数值为演示用途、非真实统计。维度：分类 4（分类/语言/许可证/生命周期）+ 数值 5（Stars/贡献者/周 PR/关闭率/依赖数）+ 时间 1（创建年份）。

## 与实现简报的偏差（如实记录）

- Prax `design_prepare_implementation` 的实现简报模板为 React/Web Desktop（框架参数为 const，仅此一值）；本交付按冻结简报"技术栈自选"采用**零依赖原生 JS**：保证 `file://` 直接静态打开、离线运行、无构建链。架构（单一状态所有者、组件契约 DATA-SURFACE / FILTER-CONTROLS / CONTEXTUAL-DETAIL、状态机）与简报同构。
- 数据集为"页内确定性生成"而非"构建期生成产物"：生成器即静态脚本 `js/data.js`，随首帧同步执行完成，行为上等价于内联数据（无任何加载态）。

## 验证状态（如实记录）

- 交互取证：8/8 步通过，全程无 console error（`screenshots/evidence-log.json`）：初始就绪、选中保持、维度切换（选中/行序/列位保持）、图例过滤（475 行淡出保留）、Ctrl+Z 撤销、数值投影、回到全集、真实键盘输入（Tab 焦点遍历 + 可见焦点 + Ctrl+Z 撤销 + 焦点恢复）。
- Prax 自动测量（3 轮用尽）后残留两项自动化失败，均已在代码中修正到本地实测通过，仅无法再触发 Prax 复测：
  - `a11y.target_size`：最后一轮报 3 个 22px 图例按钮 → 已加 `min-height:24px`，本地 CDP 实测 `undersizedCount: 0`。
  - `a11y.contrast`：最后一轮报 1 对（4.36，状态芯片"来源维度"小字）→ 已改用 `--muted`（5.3:1），全量浅色文本已抬高（--faint 5.07:1、淡出行 0.68 不透明度 ≈4.9:1）。
  - `layout.overflow`：最后一轮报 497 个（fixed 布局单元格省略号溢出）→ 已改回 auto 布局并收紧内边距，本地实测 1280×860 水平溢出 0（仅剩台账纵向滚动区，属设计内滚动容器，与 Prax 豁免的 rail-groups 同类）。
  - `a11y.focus_order`：检查器按"先列后行"（x 优先）视觉序模型报告 2 处倒置（维度面板同行按钮、台账勾选框 vs 滚动区）。本应用的 Tab 序为标准行主序（DOM 序 = 阅读序，符合 WCAG 2.4.3"有意义顺序"）；按该模型调整会迫使用户焦点在面板内上下跳跃，损害真实可用性，故保留行主序并如实记录分歧。
