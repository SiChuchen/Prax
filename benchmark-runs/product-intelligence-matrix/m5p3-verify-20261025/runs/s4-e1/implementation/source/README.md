## 验收种子落实：不可逆步骤有恢复 / 确认路径

5 个不可逆节点（债权人公告、即办/一般税务注销、银行销户、注销登记），每个都同时具备：

1. **确认路径**：完成前必须通过独占模态的「确认仪式」——后果说明 + 恢复路径 + 逐条承诺勾选；
   终步（缴销营业执照）额外要求键入公司全名。未满足前确认按钮禁用。
2. **恢复路径**：步骤卡内常驻「执行前撤回 / 执行后补救」双格；顶栏「恢复手册」抽屉汇总全部
   不可逆节点，任一时刻可查，执行后仍可回看。

## 其他防错设计（对应用户任务：零失误走完全程）

- 顺序锁定：步骤按序解锁，后续步骤仅可预览、不可执行。
- 完成门：每步前置自查清单未全勾，完成按钮禁用。
- 分支判定：税务注销前三问判定即办 / 一般通道，推荐并把不适用分支标记「不适用」。
- 口径提示：每步标注地区差异与时效，全局声明「以办理当日口径为准」（应对不确定 / 易变）。
- 全程办结页：确认统计与归档清单。
