# 驻点决策台 · 选址对比面板（cell-j09-s03）

单页静态应用：**decide × comparison-panel** — 面对位置敏感的选项做决策，
少量（2–4 个）候选选址并排高密度对比，地理语境（区位图）与决策项同屏。

## 打开方式

直接双击 `index.html`（file:// 即可，无构建、无依赖、无外部服务）。

## 与简报的对应

- **user_job: decide / 位置敏感的选项** — 在 5 个候选住址中为"迁居到启明科技园附近"选一个；
  成功标准 = 决策输入同屏可得：区位图、对比表、权重、结论始终驻留一屏，无加载态（数据内联）。
- **shape: comparison-panel** — 基数 few（默认 3 列、可 2–4 列并排）、密度 high（9 个属性维度 +
  相对条形）、比较需求 required（表体即比较态，最优值行内高亮 ▲，排名徽章 #1 常驻表头）。
- **object_type: location** — 主对象为位置：SVG 区位图（街道/河流/公园/通勤等时线）与
  对比列双向联动（悬停图钉↔高亮列）。
- **验收种子：地理语境与决策项同屏** — 左图右表同屏；推荐结论带区位理由（通勤等时线、
  距次优的租金/通勤差值）。

## 功能

- 点击地图图钉或底部候选片，加入/移出对比（最少 2、最多 4），实时重排。
- 权重滑杆（租金/通勤/居住品质）实时改变加权得分与推荐结论；可一键重置。
- 归一化评分：租金(逆)、通勤=0.7·时间+0.3·地铁站距、品质=面积/采光/噪音(逆)/便利/公园(逆) 均值。
- 自动化复现交互态：`index.html?cmp=ABCD&wr=25&wc=55&wq=20`（cmp=候选集，wr/wc/wq=权重）。
