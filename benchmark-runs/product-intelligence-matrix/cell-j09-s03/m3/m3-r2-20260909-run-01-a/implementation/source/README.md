# 落点 PinDown · 选址对比决策台

cell-j09-s03 · decide × comparison-panel · 单页静态 Web 应用

## 运行

直接用浏览器打开 `index.html`（file:// 协议即可，无构建、无依赖、无外部请求）。
初始数据内联于首屏，页面加载完成即处于可用状态。

## 产品形态

12 人研发团队在云洲市 4 处候选办公室之间做选址决策。**地理语境与决策项同屏**：
左列为城市轨道示意地图（候选地标钉、加权最优光环、聚焦虚线环）+ 比较清单 + 决策权重，
右列为 4 列并排高密度对比面板（6 项加权指标 + 10 项背景信息，共 16 行）+ 深色结论条。

## 功能

- **并排比较**：4 列固定同屏，每项指标行内嵌归一化条形图，列内最优值标「优」
- **加权评分**：6 项指标权重滑杆实时重算全表（min-max 归一 + 加权求和），含 4 组预设
  （均衡 / 成本优先 / 通勤优先 / 体验优先），预设切换即翻转排名
- **聚焦联动**：点击地图地标 / 表格列 / 清单卡片三向联动高亮
- **纳入/剔除**：比较清单勾选控制参与评分的候选（保底 2 个），剔除列变灰保留可见
- **锁定首选**：列头「设为首选」，结论条即时对比用户选择与加权最优（一致 ✓ / 差距归因）
- **行情波动**：「模拟行情波动」按钮随机扰动一处租金并记入 ticker（中等易变性）
- **状态深链**：当前比较状态自动写入 URL hash（如 `#pick=B&focus=B`、`#preset=cost&excl=C`），
  可分享、可还原，刷新后决策状态驻留
