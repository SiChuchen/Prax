> Benchmark cell: **cell-j10-s09 · complete × consequential-flow**（user_job：complete / 高后果流程；成功标准：零失误走完全程）
> 验收种子：**不可逆步骤有恢复/确认路径**

单页 Web 应用：把一次高后果操作（生产支付库主库割接，9 步 / 3 阶段 / 含 2 个不可逆步骤）
组织成"一次只聚焦一步"的执行台。护栏保证零失误可以达成，审计日志与完成判定保证
零失误可以被证明。

## 运行

- 直接双击打开 `index.html`（纯静态、零依赖、无任何外部请求；数据内联于 `data.js`，首屏即用，无加载态）。
- 或起本地服务：`python -m http.server` 后访问 `http://localhost:8000`。

## 关键设计 ↔ 验收种子映射

不可逆步骤（CUT-02 切换写入端点 / CUT-03 旧主库封版退役）各有完整的**确认路径**与**恢复路径**：

| 层 | 机制 | 说明 |
|---|---|---|
| 确认 ① | 执行门槛 | 前置核查全部勾选 + （谨慎/不可逆步骤）风险提示或**回退预案必读并勾选确认**，未满足时执行按钮禁用 |
| 确认 ② | 誊录确认短语 | 必须逐字输入步骤专属短语（如「确认切换写入端点」）；填错拒绝执行并计 1 次失误 |
| 恢复 ① | 撤销窗口 | 执行后 10s/8s 内可**一键无损回退**（实时倒计时条）；使用计 1 项偏差 |
| 恢复 ② | 人工恢复程序 | 窗口关闭后步骤"已生效"，仍展示唯一回退方式 **HP-01 / HP-02**（步骤清单 + 二次短语确认 + 双人复核说明）；执行后步骤回到待执行，计 1 项偏差；须按逆序恢复，后续步骤已推进时禁止乱序 |
| 恢复 ③ | 安全停止 | 安全核查提问答"否"（与值班面板数据不符则同时计失误）→ **阻断推进**，给出回退指引与"标记安全中止"出口，中止判定独立成页 |

## 零失误账本

- **失误**：誊录校验码错误、确认短语不匹配、核查判断与面板数据不符（每次 +1，不可逆操作均被拦在生效之前）。
- **偏差**：动用撤销窗口或人工恢复程序（每次 +1）。
- **完成判定**（走完 9 步后结算）：`🏆 零失误完成`（0 失误 0 偏差）/ `✅ 完成 · 含偏差` / `⚠️ 完成 · 含失误`；阻断状态另出 `⛔ 已安全中止`。
- 右侧审计日志全程留痕（信息/完成/执行/回退/恢复/失误/阻断/生效/中止），可截图归档复盘。
