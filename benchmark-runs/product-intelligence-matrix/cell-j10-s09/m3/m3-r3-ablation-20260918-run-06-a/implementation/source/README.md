# 发布指挥台 · Release Commander

cell-j10-s09（complete × consequential-flow）交付物：一个单页 Web 应用，让用户**零失误走完**一次高后果生产发布流程（orders-api v2.4.0）。

## 运行

无需构建、无外部服务。任选其一：

- 直接双击打开 `index.html`（纯静态，相对路径引用三个资源文件）；
- 或 `python -m http.server 8931` 后访问 `http://127.0.0.1:8931/`。

页面加载即处于可用状态：全部流程数据内联于 `data.js`，首屏直接渲染，无加载态。

## 玩法 / 验收映射

| 简报要求 | 实现 |
|---|---|
| 零失误走完全程 | 每次门禁误判记 1 次失误；全程结束输出「零失误通关」或「完成 · N 次失误」判定证书 |
| 不可逆步骤有确认路径 | 2 个不可逆步骤（数据库迁移 #217、全量切换 100%）必须输入确认短语 `MIGRATE-217` / `CUTOVER` 才能执行 |
| 不可逆步骤有恢复路径 | 每个不可逆步骤带「🔖 恢复路径」面板（执行前可阅、执行后仍可阅）；执行后卡片保留恢复指引 |
| 不确定性（中） | 4 个观察门禁的指标每次演练随机healthy/越限，用户须对照阈值人工判定；正确判「未达标」进入恢复路径（不计失误），误判记失误 |
| 易变性（中） | 门禁指标值每次加载随机；恢复处置后复判必转健康 |
| 层级（高） | 6 阶段 → 14 步骤 → 每步骤多项检查/动作/门禁，左栏时间线全程可见 |

## 文件

- `index.html` — 页面骨架 + 确认模态 + 完成遮罩
- `styles.css` — 全部样式（深色指挥台主题）
- `data.js` — 内联运行手册数据（6 阶段 / 14 步骤 / 门禁阈值 / 恢复路径）
- `app.js` — 状态机与渲染（无框架、无依赖、无网络请求）
- `evidence/` — headless Chrome 真实浏览器取证截图 + 驱动脚本 `drive.js`

## 取证

`evidence/drive.js`（puppeteer-core + 本机 Chrome）真实驱动页面走完全程：首屏、灰度门禁、恢复路径、不可逆确认模态、完成判定，共 9 张截图存于 `evidence/*.png`。
