# 维象 · 多维数据探索（cell-j13-s10）

explore × dimensional-space 单屏应用：对 240 条记录 × 15 个维度的「城市观测集」做
散点投影探索。**维度切换不重置认知**（成功标准）；**过滤/投影状态有归属且可回退**
（验收种子）。

## 运行

无依赖、无构建、无网络请求：

- 直接双击打开 `index.html`（file:// 即可），或
- 任意静态服务器托管本目录（如 `python -m http.server`）。

页面加载完成即处于可用状态：数据集由确定性种子生成器在脚本解析时同步构建
（240×15，含受控相关性），随首屏就绪，不存在加载流程。

## 使用

- **投影**：左栏「维度目录」按主题分组（5 组 15 维），每行可指派 X / Y / 颜色
  角色；切换维度只改变映射，**选中、过滤、轨迹全部保持**。
- **过滤**：每维度行内「过滤」展开编辑器（数值=区间滑块，分类=复选）。每条
  过滤器在状态条以芯片呈现并**标注归属维度**；图例中的类别芯片可直接切换保留态。
- **回退**：每次视图变更进入「投影轨迹」命名快照栈；`Ctrl+Z` / `Ctrl+Y` 撤销重做，
  也可点击轨迹任意一步跳转；「重置视图」本身也可撤销。
- **检查**：点击散点（或图表聚焦后方向键 + 回车）选中记录，右侧画像显示其全部
  15 维取值；底部「可见记录表」支持数值扫描。

## 键盘

`Tab` 遍历控件；图表聚焦后 `←→↑↓`/`PgUp/PgDn` 移动光标、`Enter/Space` 选中、
`Esc` 清除选择；`Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` 撤销与重做。

## 可达性（H-23 AA 底线）

正文 `#0b0b0b`（17.4:1）、次级 `#52514e`（7.4:1）于 `#fcfcfb`；全部文本 ≥12px；
交互目标 ≥26px（散点命中区经透明描边扩至 24px 直径）；`:focus-visible` 可见焦点。
颜色编码配图例、提示与记录表（非仅靠颜色）。

## 文件

- `index.html` — 结构（语义区域：维度目录 / 数据总览 / 状态条 / 检查器 / 轨迹）
- `styles.css` — AA 底线设计令牌与布局
- `app.js` — 数据生成、状态与快照栈、渲染与交互（原生 JS + SVG）
