# Lenscope · 多维透镜 — cell-j13-s10 (explore × dimensional-space)

单页多维数据探索工具。基准格 **cell-j13-s10**：`explore × dimensional-space`，
主对象 `dataset`，验收种子 **过滤/投影状态有归属且可回退**。

## 运行

无构建、无依赖、无外部服务。两种方式：

- 直接双击打开 `index.html`（file:// 可用，classic script，无 ES module CORS 问题）
- 或任意静态服务器：`python -m http.server 8000` → http://localhost:8000

数据（420 条 × 14 维度）由确定性种子在 `data.js` 内联生成，**页面加载完成即 ready**，
不存在可观测的加载态。

## 成功标准 → 实现映射

### 维度切换不重置认知（user_job success）

- 选区（selection）、过滤器、锚定记录、状态日志、足迹（trail）全部存在**透镜状态之外**；
  切换透镜只改投影映射（图表 X 轴 + 表格首列 + 排序跟随），其余状态一律不动。
- 可随时切：左栏维度点击、足迹 chips 回跳、键盘 `[` / `]` 顺序遍历维度。
- 切换后表格保持滚动位置（viewport 归属 record-table）。

### 过滤/投影状态有归属且可回退（acceptance seed）

- 每个过滤/投影动作（透镜、对比轴、着色、筛选、搜索、排序、清除）都在右下
  **状态日志**里产生一条具名条目：`#序号 · 动作标签 · 时间 · 可见数 · 已选数`（归属）。
- 点击任一日志条目一键恢复到该时刻的完整状态（含选区与锚点）；
  撤销/重做（Ctrl+Z / Ctrl+Shift+Z）与日志共用同一栈；恢复后前向分支保留可重做，
  直接新操作才放弃分支并明示（可回退）。
- 日志上限 80 条，超出折叠最早条目并明示。

### 交付约束

- 根路径 `index.html` 静态打开；本地离线运行；未部署到任何外部服务。
- 单页单主屏；无后端、账号或持久化服务（状态为会话内状态，刷新即回初始 —— 简报不要求持久化）。

## 界面区域（SDIR regions）

| 区域 | 内容 |
|---|---|
| header | 数据集身份 · 实时计数（共/可见/已选）· 撤销/重做 |
| filter-bar | 搜索 + 活动过滤器 chips（逐个移除 / 清除全部，均可撤销） |
| dim-rail | 14 个维度（分布 sparkline + 统计）· 透镜切换 · 足迹 |
| lens-stage | 透镜投影散点图（X=透镜，Y=对比轴，色=着色维度）· 悬停提示 · 点击选中 |
| record-table（主导面） | 投影记录表：透镜列带头（带内嵌条形）· 排序 · 行选中 · ☆ 锚定 |
| inspector | 锚定记录 × 全部 14 维度（透镜维度高亮，数值附全距条） |
| journal | 状态日志（归属 + 恢复） |

## 数据说明

`data.js` 以 mulberry32(20260924) 确定性生成 420 条合成城市记录：
11 个数值维度 + 3 个分类维度（大区 6 值仅作筛选；发展带/海陆属性各 3 值可作着色 —
着色槽位使用经全对 CVD 校验的三色序列色板，图例 + 表格视图 + 悬停提示提供次级编码）。

## 键盘

- `[` / `]`：上一个 / 下一个维度设为透镜
- `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`）：撤销 / 重做
- `Tab` 按文档顺序遍历全部控件；记录表为网格模式（`↑`/`↓` 行间移动、`Enter` 选中、`Shift+Enter` 锚定当前行）；过滤器为原生控件；搜索框与范围筛选内 `Enter` 立即应用
