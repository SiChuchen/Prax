# ASTROLABE·13 — 维度星表探索台

**cell-j13-s10 · explore × dimensional-space** · 主对象 dataset · 成功标准：**维度切换不重置认知**

一个从零实现的纯静态单页应用：对 2,600 条巡天星表记录、13 个维度做投影式探索。
切换投影维度时，**筛选 / 着色 / 操作史全程保留**；每个过滤与投影状态都**有归属**（chip
标注来源：点选 / 框选 / 维度列表 / 着色…），且**可回退**（回退 / 重做 / 回退至任意历史步）。

## 运行

无构建、无依赖、无外部服务。两种方式任选：

- 直接双击打开 `index.html`（file:// 协议即可完整工作）；
- 或本地静态服务：`python -m http.server` 后访问 `http://localhost:8000`。

页面加载完成即处于可用状态：星表由种子（seed=20260902）同步生成并随首屏就绪，无加载态。

## 操作

| 交互 | 效果 |
|---|---|
| 左栏点击维度 | 切换投影（筛选 / 着色 / 历史保留，toast 确认） |
| 点击柱条（分类/顺序/布尔） | 加入 / 移除该值筛选 |
| 拖拽直方图（数值） | 设定区间筛选；双击清除本维筛选 |
| 顶部「着色维度」 | 在投影内再叠加一维（分类=堆叠分段，数值=连续色标） |
| 状态条 chips | 每项显示来源归属，✕ 单独移除；「清除全部筛选」一键清空 |
| `Ctrl+Z` / `Ctrl+Y` | 回退 / 重做；右栏操作史可点击任意步「回退至此」 |

## 设计要点（对齐验收种子：过滤/投影状态有归属且可回退）

- **归属**：每次状态变更在 chips 标注来源（`点选` / `框选` / `维度列表` / `着色` / `芯片` / `按钮`），
  同时落入右栏操作史（S0、S1、…，含时间与描述）。
- **可回退**：快照栈支持回退 / 重做 / 跳回任意历史步；重做栈在新变更时按惯例截断。
- **认知连续**：数值轴全域固定（`data.js` 计算一次，不随筛选缩放）；被本维筛掉的值以幽灵柱
  呈现（可见体量对照）；筛选在切换投影后立即以同口径作用于新维度。
